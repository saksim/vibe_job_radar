# 0.15.5：完整导入与批次回滚

## 解决了什么

- #461：CSV 多余/缺失单元格、重复或同义表头、未闭合引号及 JSON/JSONL 重复/同义字段可能静默覆盖或截断正文。现在明确拒绝歧义输入。合法14万字符CSV不再触发默认解析上限异常，已有15万字符JD上限与50MB文件上限仍生效。
- #462：工作台已校验的批次在后续记录或审计事件写入失败时留下半批数据。现在岗位快照、逐条观察及批次审计用同一事务提交，失败共同回滚，给出权限/空间/稍后重试提示，原始上传副本留在本机。

## 提高了什么

完整JD不会因格式歧义被静默改写；重试不会继承上次失败遗留的观察记录。保留中文列名、规范附加列、引号/换行、空行的原来源编号、重复导入计数和旧快照。CLI保留逐行容错、错误清单及后续文件导入；工作台保留整批校验。原采集、完整JD、原报告、网络、调度、团队、升级与回滚功能保持。

## 实际本地验证

在准确0.15.4/main e636e0f8b1bf30f1c872be760fc0463560d5e6a6 上，11项负对照出现13个断言/子用例失败、1个CSV异常（0.277秒）；规范CSV正向对照通过。前一次测试夹具自身未关闭SQLite连接引发3个Windows清理错误，修正夹具并保留首次输出，不算产品故障。

修复后149项直接相关导入、原数据写入、工作台、HTML与原报告检查中148通过、1个既有符号链接权限跳过（8.405秒）。补充保留空行来源编号与失败后重试后，仅运行13项导入回归，全部通过（0.831秒）。测试用临时自造数据、确定性数据库触发器；不代表实站或真人验收。未重复本机全套。
