# 登录能力与首页说明

跟踪 #99，直接更新现有 PR #100；当前验收以本次提交及合并后主干的证据为准。

首页从现有适配器注册表读取公开能力、默认后端的验证状态和单次密码提交状态。工作台状态接口沿用本机令牌与来源校验，只增加公开注册表数据，不读取采集任务记录，也不会创建任务或发出招聘请求。未适配平台继续显示仅导入材料。

猎聘可由用户明确授权一次填写并提交密码；平台条款、短信、扫码和图形验证仍在程序打开的采集浏览器中处理。该功能只完成受控页面验证，真实账号登录尚未验通。页面说明不把历史公开正文或人工目录当作登录认证，也不要求把密码、验证码或 Cookie 发到聊天。当前 Chrome 选择、条款确认、频次说明和登录接续逻辑保持。

旧 PR #100 还携带 #102/#103 的状态锁修复。当前主干已具有相同的 record_lock 实现、原六项测试与调用入口，所有权文档也已说明同进程公平性和跨进程限制，本次不重复引入旧父分支。旧 Windows/Python 3.10 首次失败与后续修复记录继续保留。

浏览器验收保留原九项导入、报告、历史和公开来源流程，增加首页及向导两项能力说明检查；确认查看说明不创建任务。新增两张 390px 截图供审查。测试脚本可显式通过 RADAR_TEST_CHROMIUM 使用本机 Edge，CI 默认 Chromium 行为不变。
