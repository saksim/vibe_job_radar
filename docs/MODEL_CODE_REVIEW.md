# 明确使用语言模型审查代码

默认规则识别候选人使用、利用、运用或借助 AI/语言模型进行代码审查或代码评审的要求。模型到代码动作之间只允许已列明的辅助、执行与程度词，不按任意词距连接。要求从句首或同句明确的分隔处开始；模型产品名称后缀、代码审查产品开发和单独的模型知识不会因此成为工具使用能力。

原独立义务、否定、不要求、公司/福利标题与摘要规则保持。普通模型名不会被登记为专用编码产品；规则接受仍需人工复核，不是个人经历或能力认证。用户显式覆盖 `direct_patterns` 继续生效，规则配置及摘要随每份报告保存。
