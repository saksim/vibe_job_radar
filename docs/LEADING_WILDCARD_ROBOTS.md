# robots 前导通配符

Refs #186 / #55 / #85。

共享解析器接受以 `/` 或 `*` 开始的非空 Allow/Disallow。前导 `*` 可匹配开头斜杠，与[RFC9309 §5.1](https://www.rfc-editor.org/rfc/rfc9309.html#section-5.1)示例一致；原模式直接进入已有有界匹配器，保留后缀锚点、编码、最长匹配和同长度 Allow 优先。

此前只接受斜杠前缀，导致BOSS已保存的200/text/plain robots被整体判为不可用。对原1040字节响应离线复核后得到40条规则；查询、JS、推荐路径及其指定特殊详情仍被拒绝。人工路径的允许判断只说明规则未拒绝该路径，不证明页面存在、正文可取得或专用适配已完成。BOSS原生访问契约仍不可用，51job原HTML响应仍拒绝。

HTTP、浏览器桥和原生后端共用本修复。单规则长度、32个通配符限制、规则总数、响应大小、原爬取延迟与请求速率约束保持；普通无斜杠路径、无效响应及未知访问契约仍停止。不会通过忽略规则继续，也不切换爬虫身份。

10项新增回归包含原拒绝缓存、同源重定向和回环TLS，旧响应对照不联网、不修改原采集账本。当前提交的全量测试、CI与程序资格以对应PR为准；多站实站目标继续由#55/#56跟踪。
