# 0.20.2：分站搜索范围与原生连接关闭

基于正式 0.20.1，Refs #55、#56、#263、#436；#183、#269 继续按各自证据调查。实际完成状态以配对 PR、准确 main 的 CI、正式 Tag 和镜像回执为准。

Python 安装包属于高级安装方式，适合自行维护 Python 环境及所需组件的用户。普通桌面用户选择本机平台包即可，无须额外安装 Python 包；三类交付来自同一产品版本，Docker 用于服务器工作台。

## 解决了什么

BOSS 和 51job 已有任务翻页时，另一关键词的列表可能混入原任务。两个独立适配器复用纯关键词范围校验，对已明确包含关键词的标准搜索入口逐页核对原任务；创建时拒绝不一致或重复关键词参数。旧任务同样校验，保存的检查点和执行绑定不重写，没有已知关键词契约的手工列表及裸入口仍保留原行为。BOSS 官网公开链接使用的全国列表 `/c100010000/` 也纳入校验：带明确关键词的手工入口锁定原路径与唯一同值的 `query`，防止翻页时混入另一关键词或另一类列表。默认搜索入口保留，未推断其他城市或分页参数。51job 的 `/pc/jobdetail` 路径改为精确匹配，避免将相似前缀误认作岗位详情。

原生隧道先前在处理线程开始后登记客户端连接，关闭操作可能遗漏已接收但尚未调度的连接。本版在接收时登记并与关闭操作共用锁；线程启动失败也先关闭再撤销登记，释放原并发槽位。连接处理结束时先关闭再撤销登记，保留原取消响应、目标隔离、认证、配额和等待期限。

## 提高了什么

站点的关键词访问规则由适配器负责，任务服务只调用其契约，页面不承担该业务判断。PAC 拒绝场景复用已有守卫和握手观察，关闭前保存固定计数与阶段；观察失败不伪造零事件、不覆盖原业务失败，也不把缺失的必要观察判为成功。没有放宽网络权限、删除原断言或复制另一站的分页规则。

## 验证结果

在原 0.20.1 代码上，离线快照复现了两站跨关键词混入和 51job 相似详情路径误识别；真实本地回环连接复现了关闭遗漏晚调度连接。PAC 夹具证明原业务拒绝断言失败前缺少守卫/握手观察，仅用于验证诊断接线，不代表复现了旧云端 SOCKS 故障。修后连接生命周期17项和PAC观察链路18项首轮通过；适配器33项补验通过。适配器首次驱动在子进程返回后因日志目录权限失败，结果未知；原记录保留，仅同一33项在预先打开日志文件后补验一次，不写成首轮成功。生命周期驱动另有一次执行前的目录权限拒绝，当时0用例，修正输出位置后首次执行17项。三组均无失败、错误或跳过，实际输出与源码摘要保留；没有本机全矩阵或旧CI重跑。完整必需 CI 和正式发行各自使用新提交证据。

首候选完整CI另发现能力状态测试与生成文档仍假定两站旧定义证据匹配；按实际注册表修正为猎聘仍匹配、BOSS/51job的新定义没有可继承记录，7项原能力状态用例首次通过，历史证据与生产定义摘要不改。该候选的Chrome代理验收还在首次HTTP Basic的TLS访问失败，原日志与产物保留，底层SSL原因未知；它不经过本次修改的原生隧道。新提交必须取得自己的完整验收，不能用后续成功改写首失败。

独立代码审查另确认：观察器不可用、快照不完整或溢出但未抛异常时，原门槛仍可能登记成功。纯夹具复现了首个错误通过的场景；本版要求守卫与握手快照同时可用、完整且未溢出，原9项业务断言仍先执行并保留错误优先级。原审查、首次失败和后续定向验证分别保留，不继承前一候选的CI资格。

BOSS 全国入口另用原任务服务单例确认：Java 任务的下一页变为 Python 时，外来卡片在原代码实际落盘。最初夹具在 Windows 平台探测时被过宽的进程禁用桩拦住，尚未进入任务创建；原初始化失败单列保留，修正夹具后只执行该单个范围例。修后三个新用例、六个原范围用例与七个能力／生成文档用例共16项一次通过。官网入口观察只证明所见 URL 契约，未取得真实搜索结果、完整 JD 或分页认证。

后续候选的 Windows Edge 无界面作业在原 PAC 页面重载时，未在原5秒内等到设置按钮可用。原日志和部分结果保留，缺少当时的状态请求和服务器现场，底层原因仍未知。本版只补齐这个失败边界的被动状态请求记录及有限、无局部变量的线程代码栈，沿用原断言给出的页面信息，不增加 DOM 往返或业务请求。新增三项纯回归一次通过，核对原异常、清理、数量上限及缺失信息标记；这项诊断改进不代表已修复页面停顿。

## 剩余问题

#55/#56 仍需要可核实的正常动态访问契约、真实完整 JD 与分页证据；本版不把人工夹具或官方网页可见卡片算作实站认证。原 30 个岗位／3 日期口径保持。#183 的旧额外 GET 来源、#263 的其他旧启动/连接故障、#269 的历史慢因和 #436 的旧拒绝阶段物理原因仍未确认，不以新版通过代替。#269 本次只运行一个原有分类用例一次，1.55 秒通过、未复现；没有重复采样求绿。

保留既有服务器单人工作区、桌面、CLI、团队服务、升级与报告功能。原人工标注、项目材料、普通净机及生产环境验收继续单列；没有签名凭据，桌面发行仍 unsigned / unnotarized。#210/#320只读。
