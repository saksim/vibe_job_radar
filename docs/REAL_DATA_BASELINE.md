## 合并后如何采集本地证据

停止旧服务并更新到用户审核合并后的源码，保留原工作区、解释器、浏览器及网络偏好。
无需新增依赖，不重装 Edge/Playwright，不删除配额。

在 `/guided` 新建任务时勾选“本次启用脱敏取数诊断”，或选中已有任务后，
在空闲状态点“启用本任务诊断”。仅启用不会重试请求或补回过去的事件。
继续原本获准的一次操作后，点“本地预览诊断”。核对域名、时间、首个失败候选、
上游状态、本地策略键及 `observer_errors` / `dropped_events`，需要保留时再下载。
下载的是当前预览快照，不是完整任务记录、HAR、JD或登录材料，也不会自动发布到GitHub。
关闭诊断仅清除当前任务元数据。退出服务会丢失内存事件；开关偏好保留但下次是新 recording_id。
