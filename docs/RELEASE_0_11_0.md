# 0.11.0：Linux/macOS 完整程序包

## 解决了什么

[#399](https://github.com/saksim/vibe_job_radar/issues/399) 补齐 Linux x64 与 macOS arm64 的免 Python 下载方式；在原生系统构建并检查实际解压程序，保留 Windows 与 Python 发行。

## 提高了什么

保留捆绑浏览器、框架符号链接与执行权限，明确原工作区启动及手动升级步骤。Linux 打开系统浏览器时仅在子进程恢复系统库路径，应用自身冻结组件不变。正式发行按每个平台成功任务的实际生产时间选择唯一工件 ID，保留失败证据，复核不会重复打包已成功的平台。新增配套正式 desktop Tag 和 10 项附件；Windows Latest 与 8 项升级资产保持。

## 验证结果

本地归档边界和运行环境定向检查通过。Linux/macOS 实际程序的检查由新 CI 分别执行；准确主干、最终数量和正式 Tag 结果回填到对应 PR/Release。候选阶段不预填实际系统或正式发行成功。

## 剩余问题

支持和限制见 [完整程序包说明](POSIX_DISTRIBUTION.md)。Linux 系统库、其他架构/系统版本、个人干净设备与 macOS 签名公证需要后续实际验收；不把 CI 替代个人机器。现有真实环境、生产域名和人工材料条件继续单列。
