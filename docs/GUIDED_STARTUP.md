# 向导首次操作就绪（#77）

原HTML在defer脚本和初始状态完成前就呈现可点击按钮。CI运行35905520885出现首次“检查浏览器”无结果、45秒后仍为初始状态；材料中无页面脚本错误。实际Edge在受控延迟guided.js响应时确认原按钮仍启用，可操作控件与监听准备状态不同步。

现在向导使用原生禁用fieldset，在第一次本机状态读取和事件绑定完成后启用控件。输入、按钮和表单提交共同受到约束；普通导航链接仍可用。加载期间显示状态说明，失败不会把未准备的控件装作可用；原有运行中暂停/停止规则保持。禁用期间也不会让未绑定的表单执行浏览器默认提交。

`scripts/run_guided_startup_browser.py` 用实际浏览器和本地HTTP服务延迟脚本响应，核对可见按钮及输入不可操作、无动作提交、返回链接可用；放行脚本后首次点击只发一次检查并显示结果。还检查390px布局、无岗位记录、无采集配额消耗。健康检查结果是明确的人工缺失浏览器响应，无安装或真实招聘访问；既有浏览器健康CI继续负责真实启动验证。

仅修改页面准备状态，没有工作区迁移、网络策略、登录方式或采集权限变更。原红灯与修复后的真实测试结果记录在Issue/PR。
