## 为什么做这项变更

当前浏览器通过 `context.route` → `PinnedTransport` → `route.fulfill` 完成联网。
正常浏览器与该路径并不等价。浏览器脚本、动态请求、规则获取、正文解析的失败
以前主要以任务级错误表现，尚不足以确定用户现场的第一个业务阻断点。
重复请求头已由 PR44 修复，本项不重复开发，也不把它视为所有故障的共同根因。

D01 不改变请求次数、Cookie、HTTP 方法、规则解释、网络路线、额度或返回结果。
新观察器只接受封闭枚举、域名、固定路径模板、HTTP 状态及内部关联标识；
观察器异常不得吞掉业务异常，也不能把原先拒绝的请求变成允许。

## 当前实现与后续提案必须分开

本 PR 的已实现能力是默认关闭的元数据追踪、本地预览/下载、被动规则响应分类。
D02 的原生联网、业务访问控制、真实平台契约尚未实现。
下面各控制均是 D02 的设计门槛，不是对当前新后端能力的承诺。

| 控制 | 现有路径 | D02 拟执行层与验收 | 未解决时的处理 |
|---|---|---|---|
| 网络执行 | Python 固定目标 IP 后以 TLS 重发页面资源 | 独立浏览器网络完成；HTTP 桥不重发响应，受控服务器核对调用链 | 不宣称仅加 CDP 就实现原生网络 |
| DNS/内网与重绑定 | 公网 DNS/IP 校验与固定拨号 | 必须明确浏览器或系统出站控制；用受控私网/混合回答、重定向及重绑定正反例验证 | 单次 URL 检查不能证明连接目标固定；需要等价隔离的场景不启用 |
| TLS | 源主机验证、现有系统信任策略 | 保持浏览器验证，错误证书反例必须失败 | 禁止 ignore_https_errors 或关闭系统保护 |
| 导航与依赖 | 平台及资源域名清单、受控跳转 | 已核实的主机/导航/资源依赖清单，跨域跳转及后台请求也验收 | 未知依赖记录待审，不自动扩域 |
| 只读业务 | 采集 POST 一律拒绝，登录模式有限允许 | 搜索/翻页/详情按实际平台契约区分；用户登录单列；投递/发消息禁止自动触发 | 未知 POST 不能按方法推断为只读，也不全面开放 |
| robots | 原 parser 和当前保守错误处理 | 标准语义及来源响应状态单独测试，许可依据与 robots 区分 | HTML/不可解析不是许可；D01 的分类不改变现有决定 |
| 会话隔离 | 独立上下文、当前内存会话 | 应用专用实例；D04 再加入显式选择的本地持久化 | 不读取日常浏览器目录，不将用户勾选作为无限访问授权 |
| 配额与发布方约束 | 共享 RateLedger，动作和 HTTP 请求均计量 | 动作/业务/资源分别记录，共享已有额度；测试两后端、新任务、重启和冷却 | 不将动作数冒充硬请求上限，不删库或换后端重置 |
| SW/缓存/WebSocket | SW 和 WebSocket 阻断 | 清楚决定支持或阻断；验证拦截/计量是否覆盖、缓存是否影响观察 | 未测不宣称受控；不可因盲区悄悄失去限制 |
| 取消与清理 | 可取消任务，当前请求结束后停止 | 本机生命周期与关闭路径一致；取消后的新请求、登录弹窗、失效实例反例 | 不承诺立即撤回已发出的 HTTP 请求 |
| 访问拒绝/挑战 | 401/403/429、挑战触发暂停或冷却 | 保留语义，有界等待；不在拒绝后更换后端、身份或出口 | 缺访问条件则保持 blocked，而非换源冒充 |

## D01 的诊断数据契约

- 创建任务时可勾选“本次启用脱敏取数诊断”；旧任务可在空闲时启用。
  默认关闭。开关保存为任务偏好，事件仅在当前进程内存中保留。
- `trace_id` 对应任务 ID；`recording_id` 标识本次内存记录；重启或被缓存淘汰后
  新建记录，不伪称历史追踪仍在。内存最多30个任务，每任务200条事件。
- `span_id` / `parent_span_id`、动作枚举与内部岗位 hash 关联网络、列表识别、
  详情身份、正文提取、持久化和报告。网络回调显式绑定同一个 recorder，
  不依赖跨 Playwright greenlet 自动传播 ContextVar。
- `completed` 仅表示被观察函数返回，**不表示取得 JD**；0卡片、0可报告记录
  单独作为观察事件。HTTP错误响应与网络失败是不同事实。
- `first_failure` 保留最早失败；`first_content_candidate` 排除当前后端标为可选的资源，
  仍只是候选。`required_by_backend` 不等于已经证明是岗位业务依赖。
  环形缓冲淘汰后，首次候选保留，`dropped_events` 显示缺失数量。
- `local_block=true/false/null` 表示已知本地策略拒绝、已知上游拒绝或归属未定。
  HTTP状态、封闭错误码与策略键可用于区分，不记录异常正文或栈。
- URL 只保留域名、极小固定路径词表和固定参数名；其他路径段与参数名遮蔽，
  参数值、fragment、userinfo 永不保留。过长或无效 URL 不解析成可导出原文。
- 浏览器/系统类型、Python/Playwright/包版本和4个关键模块的 SHA-256 用于对应代码。
  文件哈希不是 Git 签名或实站认证；实施 main 与 PR head 记录在 PR/验收记录中。
- `/api/guided/diagnostics` 沿用本机令牌、同源和输入校验，只提供本地开关/快照。
  预览、下载不调用浏览器或网络；下载只使用已预览且属于当前任务的快照。
  关闭清除该任务诊断，不删除岗位、报告、会话或配额。

原始 JD、检索词和使用依据仍属于原工作区数据；本模块不宣称删除或加密它们。
元数据中的域名、时间同样可能敏感，分享前必须在本地复核。

## 规则响应分类的边界

`observe_robots` 只观察已取得的响应，无额外联网，最多检查512 KiB。
分别标注非200、HTML、编码问题、无规则行、通配/末尾匹配规则、普通规则。
它不会修改 `can_fetch` 的结果、补造空规则、自动切换入口或实现新的许可推断。
检测到扩展语义只能说明需要核对，不能把现有 parser 的返回值称为标准认证。
