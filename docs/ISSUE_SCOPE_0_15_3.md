- 站点：本人正常会话及获准的脱敏搜索/详情/分页样本与访问条件；不公开 Cookie、密码或验证码。
- 数据：真实目标 JD、来源和人工判断；真实项目的职责/指标留本机。
- 环境：普通 Windows 净机；准备好后提供已授权 Linux 项目/主机名称和域名。
- 代码签名：Windows 签名服务/证书或 Apple Developer 配置名称与位置；目前没有，不索取私钥。

历史未知原因由后续有效证据推动，不要求用户提供账户秘密，也不无限增加观察器。详细输入格式沿用 [待环境与材料清单](PENDING_ACCEPTANCE_0_15_0.md)。
