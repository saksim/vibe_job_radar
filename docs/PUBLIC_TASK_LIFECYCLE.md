# 公开任务：停止与确认继续

跟踪 #68，补齐 #30/H4 与 #9/R3 的本机任务控制。停止与确认继续已随 PR69 进入主干；此处补齐 PR88 的每日查询与所有权范围说明。

工作台公开来源任务执行时可以点“停止当前公开任务”。正在进行的只读请求按原超时结束；若本地保存尚未开始，不创建该批岗位报告。已取得的合规缓存、来源限频账本、既有岗位和历史报告保留。若本地保存已经开始，让该批保存完成并显示报告，同时说明停止请求到达的时机，不把完成结果伪装成取消。

停止后，或服务重启发现上次任务中断时，页面展示已保存的查询。“确认继续已保存的公开查询”沿用同一个任务 ID、原关键词、地区、来源、远程筛选、分页游标和限制，并增加尝试次数。刷新网页、查询任务状态、重启服务均不会自动请求来源。继续仍经过原客户端的缓存、硬失败和配额检查；停止不能清零配额、绕过等待或重新标记采集时间。

任务绑定来源契约、执行方式和可选服务地址。改变来源、地址、契约或查询条件后，旧任务不会继续；需要核对后新建任务。旧版没有绑定信息的中断记录保持可见，不猜测其执行条件。来源明确拒绝、证书错误等失败不转换成可恢复取消。

接口是本机既有鉴权边界内的 `POST /api/public/cancel`（当前 ID）和 `POST /api/public/resume`（当前 ID 与 `consent: true`）。不接受替换 URL、密码、Cookie 或其他参数；旧页面不能停止新任务。正常服务关闭会请求停止，已经开始的本地保存继续保留。

自动化回归覆盖真实工作线程的请求中停止、启动前停止、保存中停止、重启后确认、缓存复用、旧报告保留、固定案例配额不退还、来源/模式/地址变更及无效续接数据。浏览器验收沿用真实工作台与本地 HTTP 服务，以人工公开源夹具验证按钮、刷新不联网、相同任务续接及原报告生成。模拟上游用于程序验收，不是猎聘/BOSS/51job 实站成功证据。

本机主动查询的停止与确认继续已进入主干。受控每日查询由 #87 / PR #88 提供：计划默认关闭，经明确确认后才启用；保存不联网，首次到期为24小时后，服务运行期间检查计划。它使用同一任务所有权和状态锁，不能抢占其他工作台的任务。见 [每日查询](PUBLIC_DAILY_SCHEDULE.md)。开机自启、独立常驻队列、跨设备调度和三站实站登录认证仍由父目标跟踪。

同一工作区的两个工作台不会共享停止权：原执行实例持有整个任务的OS所有权，其他实例只观察，不能把活任务误当重启中断、覆盖状态或停止它。真正退出后才允许显式恢复；见 [任务所有权](PUBLIC_TASK_OWNERSHIP.md)。PR69回补PR90核心修复并保留主干已有轮询交接保护；PR88补齐调度交接回归及PR103同进程公平排队。公平性仅限同进程，不宣称跨进程或跨设备公平。
