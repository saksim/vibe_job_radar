# 猎聘搜索和登录页面的读取依赖

关联 #63 / #49 / #50 和旧 PR #196。当前仅移植固定读取契约与可选请求处理，正常搜索表单和登录接续另项整合。真人图形或短信验证仍由本人在平台页面完成。

原依据是2026-09-25的页面观察及当时保存的官方前端，详细历史分别见旧提交19879866的 LIEPIN_REGION_DEPENDENCY.md、LIEPIN_NORMAL_SEARCH_FORM.md、LIEPIN_LOGIN_UI_CONFIG.md、LIEPIN_HOTWORDS.md。本次没有重新请求招聘网站或读取私人正文，历史网站状态不作为当前认证。

生产改动只涉及 native_policy.py：搜索建议和城市目录的精确GET/OPTIONS，登录容器显示配置的精确POST/OPTIONS，以及本地阻断TLog和热门词。GET预检不能借此放行POST；原搜索和账号预检仍绑定各自方法、Origin和允许请求头。契约升为liepin_search_login_v3，现有任务继续受其原绑定检查。

配置读取不提交账号、生成或轮询二维码、发送短信或申请验证码；其响应不进入岗位观察。密码接口仍要求显式认证动作。城市建议、批量查询、其他主机、路径和方法没有开放。可选请求不出网，不使用请求额度；它们也不能取消暂停或策略撤销。必要读取收到403时保留失败，并阻止该读取及后续搜索。

离线对照的16个测试方法在旧生产规则下出现17个失败子断言和6个错误，原记录保留；移植后104项关联回归零失败、错误、跳过。11项新增测试及5项扩展方法取自旧196，当前其他断言保留。

原生CI脚本保留原十五项流程，追加读取成功到完整JD/原报告，以及城市、建议和登录配置各自预检拒绝的四项流程。使用五个独立人工HTTPS主机；六种浏览器/系统模式待各自首次CI验证，不在个人主机安装测试CA。本段描述验收设计，不声称已完成浏览器实测。

真实登录、正常搜索表单及整站可用性继续独立验收。原正文、报告、个人资料、会话和配额不重写；主机代理与信任设置保持。
