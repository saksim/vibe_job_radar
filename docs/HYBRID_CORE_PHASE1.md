# 混合模式核心施工：第一批运行时交付

总控 saksim/vibe_job_radar#3；实现 PR #31；限频 #27/#9；网络 #23；混合服务 #30；CI #28。

## 已接入的用户流程

首页“联网获取真实公开案例”→ 用户确认 → 本地异步任务 → 固定 Greenhouse 公开 GET → 原始正文校验 → 独立本地报告。进度可查询，10 分钟内复用既有结果，重复提交不新增并发请求。无需 API Key、浏览器安装、网址、代理端口或命令。失败不使用合成数据替代。它是既有公开案例的网页接线，不是 BOSS/猎聘/51job 认证。具体岗位可能失效，不伪造替代岗位。

配置了公开服务的安装实例还可以使用首页高级区的领域/岗位、地区、指定来源查询，经相同本地任务入口生成独立报告。普通网页请求不能填写服务地址或扩大来源注册表。LocalServer 的 public_client 参数由产品安装/运行配置提供，不是要求普通用户编写代码。当前源码不附生产服务地址，未配置时网页明确显示服务未上线。

## 网络实际执行而非仅诊断

network_policy.py 统一读取显式应用覆盖、系统/环境静态设置及 NO_PROXY，并生成不可变策略快照。SafeHTTP（含后台与 CLI）和 Chromium 的 Python 网络桥实际使用该策略建立 CONNECT/TLS。HTTP 客户端在创建时、浏览器会话在首次请求时固定快照，后续配置变更不在一个登录会话中任意换出口。

本阶段自动支持的是匿名、本机 loopback HTTP 代理。优先级：VIBE_RADAR_HTTP_PROXY 显式覆盖 > getproxies 得到的 https > all > 系统路由；显式覆盖不受环境 NO_PROXY 偷偷改路。系统配置按 Python 标准库当前平台能力读取，NO_PROXY 支持域名边界、HTTPS 端口、字面 IP/CIDR 和 *，不额外解析 DNS。

不支持或含凭据的有效代理配置失败关闭，不能静默回退直连。HTTP-only 环境项不错误当作 HTTPS 代理。检测/策略选择与实际连接证明分别标记。

**Fake-IP、PAC、SOCKS 自动适配、认证代理、远程/宿主机代理、网页持久策略和真实 VPN 产品矩阵仍未完成。** 本提交保留公网 DNS/IP 固定与 TLS 校验，不以放行 198.18.* 冒充兼容。没有改操作系统代理、路由或证书。PR #26 的 SOCKS5 仍单独审查，不复制或假称合并。

## 可选公开服务的实际组件与数据边界

- public_contract.py：严格查询白名单和整批结果校验，未知字段/来源、签名/登录 URL、错误类型、重复身份、过滤范围不符、不完整正文和无时区时间拒绝。来源登记只能由产品运行配置提供，服务响应不能扩大授权；来源“批准分发”标志是运营门控，不是法律认证。
- public_gateway.py：只读 WSGI 快照服务，提供 /v1/catalog/sources、/v1/jobs/search 和 /v1/jobs/{source.id}。不接受任意 URL、登录 Cookie 或账户凭据，没有外部抓取或数据写入接口。分页游标 HMAC 绑定查询、数据版本和到期时间，不能把游标当任意 URL。来源快照最多 1 万条、50 MB，是有限规模原型，不是生产容量承诺。
- public_data.py：固定服务 origin、固定 API 路径、来源范围验证、持久共享配额与本地缓存。缓存键绑定服务与完整查询，读取时重新验证，不同来源/服务不能串用。10 分钟内避免重复联网；最多使用 7 天的缓存应对明确的短暂故障，并显示 stale/refresh_error 和原采集时间。权限拒绝、证书错误和坏响应不被缓存成功掩盖。429 冷却保留，到期不会因 SafeHTTP 旧熔断状态而永久卡死。
- public_tasks.py：本机受令牌保护的异步任务，整批验证后转换为原 JobRecord/Store/报告流水线，原始/最终 URL、来源 ID、正文完整性和时间保留在 public_source.json 及其清单哈希中。缓存新鲜度与正文完整性不是同一字段，摘要不升级成正文。私人材料不会成为查询输入。

启动和状态查询不联网；联网需要明确用户同意。公开服务关闭时仍能本地读取缓存。自由查询文本可能含隐私，字段白名单不能承诺自动识别所有个人信息。服务端网关不记录查询历史，生产反向代理日志同样需要脱敏/禁用敏感内容。

**仍未交付：生产域名/部署、来源再分发许可、定时采集更新、生产身份验证/入口限流/告警、跨设备配额、长期任务调度、持久登录和安装包。** 不启动外部生产服务或付费资源；没有正式公开服务时不显示“云端已上线”。该客户端目前也沿严格 HTTP 路线，不声称已解决 Fake-IP。

## 限频与恢复

详见 HYBRID_PHASE1_PACING.md。发布方间隔、精确窗口、站点配额与冷却在同一 SQLite 事务中预留。浏览器等待时间传播到服务与界面；存活会话到时恢复安全读取，部分结果/报告和选择保留。401/403 等硬拒绝优先于后到的限频回调，防止误判为可自动恢复。非有限 Retry-After 不写入无限时间戳。
