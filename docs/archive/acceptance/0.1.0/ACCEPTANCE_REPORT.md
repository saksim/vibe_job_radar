## 3. 回归覆盖

记录结构与时区；数据库游标/Office Copilot 误判反例；否定、禁止、加分和混合子句；角色筛选；连续原文偏移（含随机化不变量）；摘要隔离；重复岗位与旧快照回填；独立职位正文与推荐区隔离；来源索引伪造；证据文件哈希；逐条映射与仅能力标签的区别；离线证据不能替代明确生产要求；百分比/百分点及 WAPE 分母；CSV 公式注入与 HTML 转义；原子输出与禁止覆盖；搜索分页、预算和服务失败；公网 DNS 固定、TLS、robots、挑战页及失败停止边界；模型提案严格校验和人工复核。

## 4. 未执行或未证明的部分

- 未使用真实搜索 API 或模型 API 凭据进行付费/实时接口联调，未访问用户账号。
- 未完成 BOSS 直聘、猎聘、前程无忧等全部平台的实站授权抓取验收；8个平台仅为域名检索配置和统一文本处理目标，不是8个已打通登录或私有接口的平台。
- 未证明全国/全平台职位穷尽性、实际仍在招聘、真实样本抽取准确率与召回率；正式使用需人工标注真实验证集。
- 未在 Windows 或 Python 3.10/3.11/3.12 上实际执行。仓库提供 CI 矩阵配置，但本次没有触发远端 CI；实际本地环境为上表 Python 3.13.5/Linux。
- 未进行大规模负载、长周期调度或生产服务部署验收；当前是本地 CLI 工具。
- 不提供向所有公司保证满足的描述，不自动补造学历、年限、工具经验、业务效果或生产经历。
- CLI 不提供 XLSX 导入/导出；另附 Excel 是展示快照。

## 5. 结论

可交付为 **本地可运行的 0.1.0 工具源码、wheel、合成演示和回归测试**。本地导入—抽取—归纳—证据映射—描述与报告链路已验证；在线发现/抓取/模型增强提供实际接口实现与模拟响应测试，但必须在凭据、权限、网络和真实样本齐备后另做实站验收。不能据此宣称全平台生产就绪或真实市场分析已完成。
