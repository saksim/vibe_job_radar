- 三方向真实完整JD及出处，12份范围/2份完整性/2对身份的真人判断。

“主机未准备”“代理协议不知道”“没有签名凭据”的回答继续有效，不重复索问。细节见[待环境与材料清单](PENDING_ACCEPTANCE_0_15_0.md)。四个历史根因是工程证据缺口，并非用户材料阻塞。

## 站点开发的最小输入与后续验收

本轮18项记录无新增材料，沿用0.15.9对BOSS/51job的94处引用、14份关键源码/测试和五个旧证据目录的核查结论：仍缺可直接用于专用实现的获准业务响应契约。现有DOM测试是人工夹具，BOSS早期robots读取修复不等于搜索/详情可用；51job返回HTML的robots现场不等于业务schema。

开始专用开发所需的最小输入是：获准列表页、对应完整详情、相邻页或结束语义、实际资源及方法契约；51job另需规则HTML响应的正确解释与真实来源。30个岗位/3个日期是后续认证条件，不是开始研发的前置要求。
