# 0.2.0 源码合并说明

关联工程 Issue #14、合并维护 #16，总路线 #3/#9。代码与说明已合并到main；没有创建正式GitHub Release/tag，不能将源码合并称为已完成正式发行。未交付范围从#14转交#9继续跟踪。

## 用户可见变化

首页新增 `/guided` 向导：平台和关键词输入、站内列表发现、自动汇总详情链接、勾选正文采集、本批报告和CSV直接下载。原高级URL/Search API/JSON源及证据界面保留。

可选真实Chromium采集后端；平台原生页人工登录、人工接管与同一会话后续自动采集。应用不接收账号密码、会话不持久化，不自动接受网站条款、不代投递。

按工作区/站点共享的硬限频与冷却，后台批次任务，暂停/停止/中断提示。页面关闭后当前批次继续，关闭服务后登录状态丢弃；不是常驻定时调度器。

DNS诊断展示真实解析地址，识别198.18.0.0/15提示，不关闭公网检查。依赖安装是明确确认后的固定命令，使用原Python解释器。

## 数据与兼容

新增`guided/`任务及限频数据库；主库、报告和个人证据沿用现有位置。新增`browser_fetch`来源模式，旧代码不保证能读新记录，升级前先停止服务备份整个工作区。不会自动迁移或上传本机浏览器Cookie。

## 合并前修复

翻页动作只计额一次；等候岗位选择时冻结轮询；登录打开按钮执行独立配额；可选资源401/403不误触发整站冷却，任何429仍停止。批次后续失败也生成已有成功记录的报告；自定义适配器保存报告配置；card_selector真正限制发现范围；版本号由单一源派生到包、CLI和报告。

## 验收与边界

保留原测试，增加协议、解析、状态、共享配额、网络边界、HTTP和合并审查回归。双浏览器E2E验证人工登录、动态列表、跳转真实URL、入库与报告；新增真实15秒默认限频下的普通翻页测试。

本次内置三站页面配置未完成用户真实账号的实站认证，仍为not_live_verified。公开页面可用性不由受控测试证明，登录/robots/资源域名/DOM差异可能需要逐站迭代。源码包不是带Python/Chromium的免安装EXE。

账号密码自动填入未交付，目前为人工原生登录；未创建正式release/tag。自动填密、逐站实测及长期调度等后续需求见#9/#3，交付Issue #14关闭不表示它们已经完成。
