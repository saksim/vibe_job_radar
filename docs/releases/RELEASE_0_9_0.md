# 0.9.0：跨平台域名 PAC

## 解决了什么

[#389](https://github.com/saksim/vibe_job_radar/issues/389) 补齐 Linux/macOS 无法使用 Windows 域名 PAC、完整网址 PAC 又不能接入原生浏览器的缺口。新增独立的跨平台域名范围及可选 DNS 助手，三个工作台共用明确选择、导入、检查和撤销。

## 提高了什么

脚本只收到 HTTPS 根地址和域名，HTTP、请求桥与原生浏览器共享首次域名路线。保存和状态读取保持离线，旧许可不扩大；配置重开、撤销和缺失组件明确处理。沿用原引擎限制、公网/TLS 校验和失败停止规则，保留原 PAC、HTTP Digest/Basic、SOCKS5、升级断点续传与自动交接、团队服务、采集和原报告功能。

## 验证结果

本机 52 项定向检查通过，含真实隔离引擎、人工 HTTP/SOCKS5/TLS、API 权限、重开与发行门禁。实际 Edge 155.0.4283.45 三页面、390px、独立范围与撤销通过；零外部请求、零页面错误。首次缺少可选运行库的结果保留。CI 原矩阵、实际原生浏览器和冻结程序结果以准确提交及正式 Release 为准，不预填通过。

## 剩余问题

[使用范围和降级步骤](../PORTABLE_DOMAIN_PAC.md)：旧版本不支持新网络偏好，降级前须切回旧模式。Mac 原生浏览器、企业/VPN/多网卡、代理端 DNS、其他认证和程序签名仍单列；人工 JD、本人材料和生产主机域名尚需提供。人工 TLS 场景不能代替真实站点和账号链路。
