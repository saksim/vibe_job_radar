# 0.15.9：网络、升级、资源清理与公开案例报告修复

基于正式0.15.8，按dev→release→main晋升；正式交付以Tag和附件为准。

## 解决了什么

- #486：公共HTTP请求和浏览器网络桥现在拒绝Content-Length尚有剩余却提前EOF的正文，避免有效JSON/HTML前缀被当作完整成功响应继续处理。
- #487：下载或安装请求等待启动、执行安装预检期间，如果另一次版本检查更换或撤销选择，启动worker时会在同一把锁内再次核对目标与状态，旧确认不能继续执行。
- #488：浏览器上层清理分别尝试策略、浏览器、驱动、请求调度器和隧道，保留首个异常并通知既有关闭不确定保护；清空停止会话的请求状态，启动失败分类不再被清理错误覆盖。

- #490：隔离vault夹具的剩余socket超时封顶原20秒，防止相同单调时钟tick的浮点运算产生略大于20的值；绝对deadline、到期拒绝和原断言保持。
- #491：Windows候选资格结束前保留有界、结构校验后的原失败JSONL，避免临时目录清理删除调查证据；缺失或非法证据明确记录，不改变原失败与期限。
- #492：公开案例使用内存批次作为报告输入，省去正式源记录提交后的临时磁盘SQLite及只读复制；正式数据库、全部报告文件和每文件fsync、历史/latest审计保持。

- #493：按跨平台大小写折叠检查报告附件名，拒绝原产物及manifest的大小写别名，合法附件保留原拼写；错误时不发布报告。

## 提高了什么

减少不完整响应进入JD与报告链的风险，保持升级确认与执行目标一致，使异常路径仍尽力释放其余自有资源。保留原采集、完整JD、原报告、认证、DNS/TLS、调度、下载续传、备份/回滚和升级功能；没有延长期限、删除fsync或放宽断言。清理仍是有限尽力操作，不承诺任意操作系统故障都能强制退出，也未测得可泛化的速度提升。公开案例减少了无必要的临时数据库写入和复制；这不代表已解释Windows等待失败。
