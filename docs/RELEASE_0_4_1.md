# 0.4.1：Windows 升级长路径修复

关联 [#356](https://github.com/saksim/vibe_job_radar/issues/356)。

## 解决了什么

0.4.0真实公开ZIP完成下载与SHA256校验后，在深层工作区解压Playwright文件触发WinError 206。0.4.1为解压、下载文件操作及失败清理使用Windows原生长路径；保留全部依赖和原路径/链接/目录归属检查，不修改系统设置。

## 提高了什么

长包内路径可以完整准备到独立目录；中途失败只清理本次拥有的暂存目录，已有工作区、旧程序及通过摘要的ZIP保留。正常目录与原本机任务、租约、报告、材料和CLI行为保持。

## 验证结果

首次真实包失败及栈保留；复用同一379762803字节官方包做离线修复验证，不重新下载。新增超过260字符路径与写入长文件后故障清理两项回归。实际结果、准确main资格和新Tag公开证据记录到对应PR、#356和Release，不用开发测试代替发布核验。

## 剩余问题

Windows包仍未签名；系统文件管理器和外部程序的路径能力可能不同。0.4.0的现有升级器不因服务端发版自行修复，首次取得补丁请手工下载0.4.1 ZIP。没有自动执行、覆盖旧程序或迁移工作区；生产部署、人工材料/金标准和现场验收仍保持原条件。微软[长路径说明](https://learn.microsoft.com/en-us/windows/win32/fileio/maximum-file-path-limitation)解释原生文件操作与系统设置、Shell能力的区别。
