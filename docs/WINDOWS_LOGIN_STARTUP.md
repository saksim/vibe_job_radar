# Windows 登录后启动工作台或已确认公开查询

Refs #105 / #120 / #9 R3 / #30 H4,H6 / #87 / #91 / #115。此候选默认关闭，只支持 Windows 便携包。源码版和其他系统继续手动启动。它补充既有本机每日计划，不是无人登录的系统服务。

首页“本地数据与辅助工具”下方展开“登录 Windows 后启动”，核对当前 exe、工作区和启动方式，勾选后启用。方式默认“打开工作台”：下次当前 Windows 用户登录时打开该程序、网页和可关闭的终端。“只运行已确认公开查询”启动[独立进程](PUBLIC_WORKER.md)，不打开网页服务器或浏览器；没有确认过的每日计划或一次性待办就等待。两种方式都保留可关闭的终端，关闭它结束本次进程；关闭工作台网页不结束进程。启动过程只读取设置，不自动安装或修复启动项。

更改方式会清除未提交的勾选，必须按新方式重新同意。已有登记时不能直接切换：先“关闭登录启动”，再选新方式并明确启用。重新打开页面会显示实际已登记的方式，不根据残留回执默认选择worker。独立进程运行时仍可手工打开同工作区工作台查看原报告和停用计划；原所有权防止重复执行。

每日计划独立保存、默认关闭。用户已启用的计划仍遵守原24小时间隔、条件绑定、最多补一次与失败暂停。#131的[一次性待办](PUBLIC_QUERY_QUEUE.md)默认空、逐条另行同意并在24小时内有效；原启动登记无需迁移，登记本身不授予待办许可。开启登录启动不创建查询、不自动登录招聘平台，也不替用户选择计划或待办。

“关闭登录启动”只移除下次登录的登记，当前任务和计划保持。移动或升级便携包之前，从旧包关闭登记，再关闭工作台并备份原工作区；打开新包后核对路径、重新勾选。若直接换包而保留原工作区，新包显示旧路径登记，允许关闭旧登记，然后重新选择；不会静默改指向。若移动工作区，也应先关闭旧登记，否则它仍指向原工作区。回退版本不会理解本功能，应在回退前关闭，或从 Windows 启动应用设置核对登记名称。

## 状态与实现边界

- 只使用当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `VibeJobRadar.<工作区摘要>` 单值；不使用系统用户、RunOnce、计划服务、密码或任意脚本。
- 命令固定为当前 `VibeJobRadar.exe --workspace <当前目录>`；独立进程仅增加固定 `--public-worker`。两个路径正确引用，不使用shell；拒绝自定义模式/参数、控制符、引号、环境变量占位符、UNC与超过260 UTF-16单位的命令。过长时先选较短目录。
- 本机回执先原子保存，再写登记；崩溃/写入失败后根据真正注册表值判断状态。旧页需带当前修订，两个本应用实例经原OS锁串行更改；不匹配的外部值、损坏或异工作区回执均拒绝覆盖/删除。
- 原工作台v1请求和回执继续兼容；新版页面带明确方式和v2许可，工作台仍保存v1回执，worker保存schema_version=2及固定mode。回执沿用历史文件名`windows-startup/registration-v1.json`，版本以内部字段为准。旧版本拒绝worker回执，不把它误认成工作台；回退前用新版关闭登记。若需要恢复旧工作台登记，用新版明确选择工作台后重新启用即可写回v1，不删除配额或计划。
- 注册表没有提供本流程使用的跨外部工具原子比较交换；操作前和回读均核对自身项，不宣称能阻止同用户外部工具在检查与写入之间并发修改。回执不是启动成功证明。
- 界面显示“已登记”。Windows可能延迟执行或由启动应用设置禁用；本应用不修改系统的独立开关，不保证精确登录时刻启动。实际重新登录、睡眠/重启后的长期计划验收单列，不能用登记回读替代。
- 本机离线/浏览器测试使用隔离注册表。只有显式 `--verify-login-startup` 且位于临时 GitHub Actions runner 时，便携验收才执行实际exe的两种登记、第二进程回读、移除及失败清理，并实际执行登记的原样worker命令，确认空计划不联网、不创建任务。普通本机构建/验收不写真实登录启动项。候选资格同时要求`startup_registration_verified`与`startup_worker_verified`，同一head是否通过须核对PR。失败保留阶段和脱敏错误类型，不上传完整命令、工作区路径或原始系统异常。

依据：[微软 Run/RunOnce 契约](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)规定登录触发、260字符上限及可能延迟；[Windows 启动应用管理](https://support.microsoft.com/en-us/windows/experience/startup-boot/configure-startup-applications-in-windows)说明用户可在系统设置管理启动。三站实站认证、无人登录的服务执行、跨设备队列仍未完成。
