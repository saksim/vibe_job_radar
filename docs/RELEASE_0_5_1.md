# 0.5.1 更新检查中断后的恢复

## 解决了什么

- [#366](https://github.com/saksim/vibe_job_radar/issues/366)：官方小文件已读取但后续DNS过期时，再次检查原本会重复下载前面的文件；现复用当前会话内按官方摘要核验的内容。
- 更新界面区分已知的加密DNS连接失败/结果过期和PAC执行、清理或DNS错误，未知异常不展示私有文本。

## 提高了什么

每次显式检查仍连接官方Latest，只有当前清单中摘要和长度一致的内容可复用；最多7份/7MB，退出后消失。完整元数据交叉校验、ZIP核验、备份与自动交接、旧功能和数据保留。未放宽DNS/TLS、选路、取消或配额规则，没有自动网络重试。

## 验证结果

真实触发记录：0.5.0正式main通过26/26检查，公开Tag和8资产已匿名确认。本机一次官方更新检查完成六份小文件后第七份因encrypted_dns_expired_answer中断；另一轮为encrypted_dns_unavailable。原始失败保留，定向检查与最终发行结果见本补丁PR/Release。

## 剩余问题

不保证物理网络始终可达。一次Conda源码PAC子进程清理失败含WinError5，随后12次有界离线观察通过，原因仍未确定，不冒称本缓存修复消除该历史故障。真实设备/企业网络、签名、其他系统、人工JD和本人材料、生产主机/域名继续单列。0.4.1及更早首次取得升级器仍需手动启动新版。
