## 实际观察

| 路径 | 已有结果 | 尚未证明 |
|---|---|---|
| 猎聘原生实验模式、本机 Edge、关键词“架构师” | 原工作台在 `1987986` 开发实例取得一页42张搜索卡；任务停在选择阶段，本地密码表单已准备 | 42张卡不是42份正文，也不代表全部符合目标；该任务仍0登录、0完整JD、0新报告；不认证其他关键词、地区、浏览器或网络环境 |
| 猎聘公开分类及已观察相邻页 | 89个不同完整职位URL，其中49个匹配原目标规则；原报告94条要求，24规则接受、70待复核 | 匿名分类不能替代正常登录、关键词选择后的完整JD和会话恢复验收；规则接受不是人工批准 |
| 实际日期 | 9月24日原样本；9月25日另采3份完整正文，均为原名单重复岗位，独立保留报告 | 只有两个真实日期，不增加不同岗位数；第三日期、人工身份/全文审核及建议阈值核准仍缺 |
| BOSS | 公开首页一次观察有107个职位链接；所选详情跳向登录/验证 | 未取得完整JD；日常浏览器对照和程序端专用链路仍待验证 |
| 51job | `robots.txt` 返回HTML，程序停止 | 未确定是统一回退还是访问限制，不能据此认定允许采集 |

猎聘单页搜索由原工作台HTTP接口发起，界面显示列表并展开登录表单；不把它表述为完整前端交互验收。登录仍需用户在本地表单填写账号并明确授权，平台所需验证由用户在采集浏览器完成。完成后继续选择相关岗位、获取完整正文并进入原报告，才有对应的登录后闭环证据。账号、验证码、原文与私人报告留在本机。

本页仅同步已有观察，不再发站点请求，不更改后端默认值、访问契约、配额、认证等级或历史报告。默认浏览器桥不能继承原生实验模式的这次搜索观察；BOSS和51job也不能继承猎聘结果。三站仍无 `pilot_verified` / `live_verified` 认证。
