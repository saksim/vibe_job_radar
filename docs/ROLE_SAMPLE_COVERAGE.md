# 各岗位方向的样本覆盖

Refs #213 / #210 G02。原研究简报只列分方向已接收能力，无法直接区分没有完整正文与已有正文但没有已接收AI编程证据。现在新报告在同一简报中列出方向计数，原筛选、去重与能力频次算法保持。

## 两个不同的岗位分母

- 完整正文岗位数：本批被选中、具有完整正文的原去重岗位组，包括没有提取到AI编程要求的岗位。
- 含AI证据岗位数：上述岗位中至少有一条正向、已接收AI编程要求的岗位。原能力频次继续用这个分母。
- 同一正文对应多个能力行、重复来源，不增加去重岗位数；未知公司仍按原规则保留不同来源。
- 同一岗位可属于多个方向，各方向计数不能简单相加。只展示本次选择的方向。

每方向另列纳入来源记录、全部要求行、待复核行，以及正向AI要求中的规则接收行/人工确认行。否定、普通岗位能力、摘要和待复核项不进入正向已接收证据；规则接收不计为人工确认。计数不代表标注准确率、全市场比例或本人能力。

## 原报告链路

分析时为纳入的 input_audit 行记录原 job_group_id；其他筛选和字段含义保持。研究简报 JSON、Markdown、报告 HTML 与工作台显示同一组 sample_counts、sample_status 和 sample_note。

状态分别说明本方向无完整正文、有正文但无已接收AI编程证据、已有本批证据。没有增加样本充分性或市场认证阈值；少量岗位仍需谨慎归纳。

旧报告没有这些字段时，界面和简报兼容视图明确显示“未记录”，不将缺失填为0。数据库增加新记录后，已保存报告的统计及字节保持。需要新的统计时生成独立报告，不覆盖历史，也不为补计数访问平台或登录。

## 验证边界

回归覆盖重复来源、未知公司、多方向交叉、方向筛选、摘要和排除项、否定/待复核/人工确认、旧报告以及HTML/Markdown转义。实际浏览器夹具验证工作台显示和旧报告兼容，数据为人工构造，不是招聘市场或本人经历。

真实样本的方向覆盖、真实标注集及人工复核仍按 #210 推进。本改动提供可核查的分母，不等于已补齐算法岗位样本或完成G02/G03。
