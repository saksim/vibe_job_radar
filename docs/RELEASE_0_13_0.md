## 解决了什么

Linux/macOS 的版本面板以前只识别 Windows ZIP。本版按 Linux x64 / macOS arm64 选择同版本 desktop 正式发行，核对平台、来源、完整摘要、实际程序证明和全部主干 CI；不支持的架构不会收到错误平台包。

## 提高了什么

原生完整包复用断点续传和独立目录准备，保留内部符号链接及执行权限。明确确认后先预检新版，再等待原程序退出、备份工作区、核对新程序就绪并提交入口切换。失败保留原程序、数据和已完成备份；保留 Windows 自动升级、采集、完整 JD、原报告、团队与网络能力。

## 验证结果

定向校验涵盖错平台/错来源/缺失交接证明、完整归档和退出管道；原生构建在真实 Linux/macOS 程序中验证旧程序退出、新程序就绪、SQLite/原文件及备份保留和拥有的子进程清理。正式发版只复用该准确 main 的合格产物，所有原功能 CI 门禁保持。最终实际结果见对应 Issue/PR 和发行附件。

## 剩余问题

0.12.0 及更早原生包需先手动更换一次才获得升级入口；源码安装不自动替换 Python。包未签名、公证，个人净机、换包后个人钥匙串授权、真实企业网络和其他系统/架构仍需独立验收。生产主机/域名、真实 JD、人工标注、本人项目材料尚未就绪；历史未知故障和登录专项继续单列。
