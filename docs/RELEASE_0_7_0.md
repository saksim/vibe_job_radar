# 0.7.0：跨平台 Python 安装发行

## 解决了什么

已有Python的Linux/macOS和Windows用户可获取正式wheel及源码发行包，无需源码目录即可使用工作台、导入与原报告。Python包采用独立python-v版本Tag，与Windows正式Release互链，保留旧Windows更新器的8项资产及Latest契约。关联 #372 / #30 H6 / #57。

## 提高了什么

从干净提交的受限产品文件构建并绑定摘要；同一个wheel在三系统隔离安装，源码包独立复建核对产品字节。正式发行复用已验产物，核对准确main、完整CI与每个平台安装/重启证据，并验证上传摘要。原采集、JD、网页、团队、自动升级与手工运行方式保留。

## 验证结果

本机首个Windows候选wheel/sdist构建、全新虚拟环境离线安装、五个入口、网页资源、人工JD/原报告及独立进程重开通过；源码包重建出的产品文件完全一致，0外部请求。发行门槛拒绝错提交、错wheel、错平台和不完整重启证据。当前准确候选/最终main的三系统CI与正式Tag仍以PR/Release实际结果为准，不预填通过。

## 剩余问题

需要Python3.10+，浏览器和可选组件另按原指引安装；不是免Python的Linux/macOS桌面包。签名/公证、真实浏览器与干净机器/网络场景未认证；生产主机域名、人工JD标注、本人材料与真实招聘登录条件继续单列。Windows专有的DPAPI/PAC/自动替换范围不自动扩展。
