# Fake-IP：本机可选加密解析（#23 / #3）

本文记录原有“仅修复映射地址”模式及其历史交付。#23另增加独立许可的[公共域名模式](PUBLIC_DNS.md)，不扩大本模式的触发条件或复用旧授权。后文的高级采集接线阻断是原时点记录，已由PR66接通，当前边界见[网络状态](NETWORK_COMPATIBILITY_STATUS.md)。

## 基线与完成范围

从合并 PR32 后的 main `8c983bb95bce00ef272c03985d16694a4ecea437` 开始；此前实现和未合并 PR29 均保留。本轮在 HTTP、公开目录和浏览器 Python 请求桥中接通 **有明确本机授权的 198.18.0.0/15 映射地址修复**。不是全 VPN、全 TUN、PAC、认证代理、任意 Fake-IP 地址段或招聘平台认证完成。

无需部署本产品服务器，无新运行依赖。程序不修改系统代理/DNS/VPN，不扫描端口。Cloudflare 为外部解析服务，不是我们上线的生产服务。

## 普通用户操作

本地首页、浏览器向导、高级页顶部都有“网络自动适配”。阅读说明后勾选同意并保存一次。新公开查询和新浏览器会话使用保存的设置。无需填写 resolver URL、端口或环境变量。默认关闭，正常公网 DNS 无额外解析请求。

已有会话不偷偷换网络：启用后旧浏览器会话需要停止、再继续或新建。关闭授权后，旧策略引用也不能继续发出新的 DoH 查询；已经发出的请求不能撤回。设置只属于此工作区；不是 OS 全局设置。

加密解析会向 Cloudflare 发送目标域名及 A/AAAA 类型；服务可看到网络出口。不会发送职位路径、URL 查询参数、搜索词、Cookie、认证头、简历、个人证据或正文。不承诺匿名、DNSSEC 独立验证或零第三方元数据。

## 真实运行路径

1. 先校验 HTTPS、域名许可、来源停止状态和请求节奏。
2. 使用现有系统 DNS。全为真实公网时直接沿原路线；没有额外 DoH。
3. 仅当 **所有**系统 DNS 结果都在 `198.18.0.0/15` 且用户已同意时，查询已固定的解析服务。混合公网/映射/私网、真实私网、DNS错误、localhost、特殊本地域名、字面映射IP不触发修复。
4. 以 RFC8484 POST 二进制 DNS 格式查询 `cloudflare-dns.com/dns-query`。只使用官方 bootstrap 公网地址，以原解析主机名校验证书，不递归解析 bootstrap，不接收自定义服务地址、不跟随重定向。
5. DNS 请求使用目标原本选中的同一个应用代理/系统路线。解析域名自己的 NO_PROXY 不会让已选代理漏成直连。代理拒绝停止，不换供应商/身份/出口绕过拒绝。
6. A 与 AAAA 均校验完成后，保留属于原查询 CNAME 链的公网地址；私网回答不静默过滤。继续原数字地址连接、目标域名 SNI/TLS、robots、配额和请求不重放保护。绝不连接映射IP。

HTTP及浏览器节奏等待在加密解析之前完成，避免等待期间耗尽TTL。DNS缓存按工作区对象、域名及网络策略指纹隔离，至多256条、最多300秒且不超出TTL/HTTP Age/max-age。不保存域名历史至磁盘，不使用过期DNS缓存。公开岗位缓存与DNS缓存独立：解析临时不可用时可展示明确过期的已取得岗位，保留原采集时间；解析证书、权限、私网或坏响应不能被缓存掩盖。取消、禁用、时间回拨、半成功解析、异常响应都不会得到伪成功。

## 边界与限额

二进制响应上限65535字节，最多256条记录，压缩指针和CNAME深度有界，校验问题名/类型/ID/响应标志/长度/来源。未实现的 DNAME 等回答类型保守拒绝。无 ECS、客户端标识或隐式Cookie。

每次成对解析至多2个HTTP请求、合计10秒（系统 getaddrinfo 本身仍受操作系统解析超时控制）；同一工作区对象至多60次成对查询/5分钟。失败至少30秒保护，429按更长Retry-After等待。DNS节奏预算是本进程防风暴保护，不宣称跨进程或跨设备统一配额；源站持久配额仍由既有限频账本执行。

仅 HTTP/1.1 DoH 客户端，RFC8484 推荐的 HTTP/2 多路复用尚未实现。DNS A/AAAA 并非职位数据请求，但都算真实额外网络访问，不能在说明中隐藏。

## 设置与接线

`network-preferences.json` 只保存版本、模式、修订号、同意版本和时间。API要求原本机Token/Origin、明确布尔同意和修订号，拒绝额外字段、任意端点及凭据。符号链接/文件损坏不启用修复；保存不会联网测试。新创建工作区默认无授权。

`Workspace.network_policy()` 与共享 `PublicResolver` 用于本地公开目录、单岗位例子及网页搜索；`GuidedService` 在执行线程传递策略，已有浏览器会话保留快照。**高级批次采集器 collection.py 的新接线写入被工具安全检查拦截，保持已合并main原文件，不通过其他编码/接口重发；其URL/Search/Feed批次仍不自动采用本次工作区DoH偏好。** 该缺口保留在#23，不标为完成。直接使用独立 `SafeHTTP` 库时仍默认关闭，调用者必须显式提供获准策略。

## 验证分层

- 离线单测：二进制压缩/长度/CNAME/TTL、假IP识别、混合私网、取消、禁用、策略快照、缓存、冷却、预算、授权及本机HTTP接口。
- 真正本机TLS：人工系统映射 → 加密DNS POST → 原目标证书验证后的GET；以及同一个真实HTTP CONNECT或匿名SOCKS5代理转发、解析端及目标端错误证书、私网回答、拒绝和隐私边界。测试公钥/私钥为单独自签测试夹具，生产无信任开关。
- 真实Chromium：三种页面授权、保存、刷新与撤销；只访问本地接口。
- 明确`--live`烟测：只将固定公开来源的本机DNS答案模拟为映射地址，其余为真实Cloudflare DoH、真实目标TLS和一个固定公开GET。只保存元数据/正文哈希，不上传正文。这仍不是某个VPN产品的现场实测。

每个提交的本地测试和实际CI分别记录，旧绿色状态不能替代本轮。失败保留明确信息，不为了绿色CI跳过解析或改用模拟岗位。

## 回滚

先停止任务并保留工作区。关闭网络偏好可恢复仅系统DNS；不会修改或删除原限频库、报告或采集记录。旧版不认识新偏好文件，不具备此修复能力；无数据库迁移。PR29发布工具继续单独验收，生产Linux服务后置。
