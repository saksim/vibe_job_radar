# 0.18.0：高级采集后台化与正式容器镜像

关联 [#506](https://github.com/saksim/vibe_job_radar/issues/506)、[#507](https://github.com/saksim/vibe_job_radar/issues/507)，继续由 [#57](https://github.com/saksim/vibe_job_radar/issues/57) 记录范围。版本按 dev → release → main 晋升；正式 Tag、GHCR 镜像及匿名拉取结果以实际发布回读为准。

## 解决了什么

- 搜索 API、已确认 URL、授权 JSON 源使用已有 CollectionRunner 在后台推进，页面不再循环触发 step。页面关闭或刷新后，服务进程继续完成已经接受的有限任务。
- 保留分类路线、原 step API/CLI、共享配额、任务所有权、原文和原报告。启动后仅观察状态；暂停后只执行原任务尚未完成的步骤，不重放已失败或结果未知的请求。
- 新增 Linux amd64/arm64 容器候选与正式发布链路，镜像绑定来源、版本、基础镜像和候选摘要。Compose 默认使用正式镜像，源码构建保留为独立覆盖配置。

## 提高了什么

采集流程的执行归应用服务所有，网页成为发起和观察入口。搜索 Key/数据源 Token 只留本次 worker 内存，接受后清空表单，结束释放；状态和检查点不包含它们。部署者可使用经过版本绑定和匿名启动验证的镜像，减少在目标主机自行准备构建环境的步骤。

## 验证结果

本轮本地定向结果：

- 后台采集 26 项通过（新增 7 项、原分类后台 19 项）；应用与服务器相邻 19 项通过。
- 真实 Edge 的后台页面 6 项、未修改的原恢复场景 3 项通过；夹具限定离线上游，页面没有直接 step 请求、带 Key 的轮询或外部来源请求。
- Docker Desktop Linux amd64 实际构建一次并通过 22 项 HTTP、权限、原报告与持久化检查；停止均 exit 0，测试容器、卷和临时 secret 已清理。此项使用未提交的本轮源码，不冒充准确 main 或双架构正式镜像资格。

容器发布协议的定向测试与审查结果随 PR 记录。完整跨平台源码、打包、浏览器及两架构候选由功能 PR 和最终 main 的 CI 核验；中间同树晋升保留必要检查，明确取消的重复重型作业不算通过。正式 Tag、镜像公开状态、匿名双架构启动及准确 digest 以发行回执为准；上一版证据不替代本版验收。

## 剩余问题

单拥有者、单工作区、单进程边界保留；没有多人隔离、远端招聘登录接管或无限后台调度。进程重启后需要人工核对并恢复，必要凭据需重新输入；未知请求结果不自动重放、已消耗预算不退款。

真实生产主机、域名、HTTPS、出口网络、实际工作区升级与备份恢复仍需目标环境验收。原18项 Issue、#183/#263/#269/#436 根因和 #23/#30 既定范围保持，#210/#320 只读；真实 JD、人工标注和项目材料条件未因后台化消失。没有可信 Windows/Apple 签名凭据，桌面版本仍如实标示 unsigned / unnotarized。
