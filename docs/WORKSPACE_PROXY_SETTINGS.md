# 工作区网页代理偏好

Refs #81 / #23 N3。基础页、高级采集页、采集向导共用“网络自动适配”控件。自动模式沿用应用专用环境配置及支持的系统静态发现；固定模式只接受用户明确提供的匿名loopback HTTP或SOCKS5地址及端口。保存不拨号、不测试来源、不修改环境变量或系统设置。localhost规范为127.0.0.1，IPv6 loopback也可使用。

固定模式不接受URL账号密码、远程/VM地址、路径、PAC、SOCKS4或socks5h。已有应用专用HTTP/SOCKS覆盖或任何代理凭据环境变量时，固定模式明确拒绝；若这些变量在保存后才出现，后续策略报 `workspace_proxy_environment_conflict` 并在目标DNS前停止。不会把应用凭据交给另一个工作区入口。自动模式仍可使用#76已经支持的认证代理。

两种偏好共用修订号，保存DNS保留代理，保存代理保留DNS；过期页面必须刷新，不能覆盖新配置。每个工作区独立，路由进入同一 `NetworkPolicy`，公开数据、高级URL/Search/Feed、CLI及新浏览器会话均按工作区捕获快照。已有浏览器保持原快照；更换设置后需要停止并重新打开，不能把改配置当成已有登录会话已换路线的证明。

网络策略仍检查公网目标、原域名SNI/TLS、配额与robots，代理拒绝不直连。匿名代理URL不是凭据，但仍只保存本机工作区，状态不宣称网络测试或实站认证。界面初始化/保存时用fieldset禁用全部偏好控件，其他页面渲染不能提前启用它们。

## 格式和回退

原有v1 `network-preferences.json`继续读取。只保存DNS仍保留v1；首次保存工作区代理时写v2并添加代理模式、规范地址、同意版本。改回自动也保留v2，避免旧源码忽略未知字段后悄悄换路线。旧源码读取v2会明确报不兼容，离线正文、报告和个人证据不受影响。

回退前停止服务、备份整个工作区；旧源码需恢复原来已知有效的v1网络偏好备份。不要删除数据库、配额或Cookie，也不要手动把版本号改成1以绕过验证。没有备份时保留v2文件并用兼容的新版本处理配置，不将静默恢复系统网络当成回退成功。

验证分为人工真实HTTP/SOCKS/TLS、网页跨入口/重载/修订冲突/工作区隔离，以及旧源码拒绝v2。具体精确head与CI结果在PR记录。PAC、VM、代理DNS、真实VPN组合、#63页面空白和真实登录/完整JD/跨日期仍未由本项解决。
