# 猎聘正常搜索表单

关联 #49 / #63，继续原 PR196。默认关键词任务进入正常无参数页面，填写页面上的搜索框并按一次 Enter。此文说明实现和可验证边界，不表示真实账号或关键词链路已经验通。

## 依据与行为

2026-09-25 实际入口保留的 DOM 包含 `input[type="text"][placeholder="搜索职位、公司"]`。[官网当前 common 脚本](https://concat.lietou-static.com/fe-www-pc/v6/js/common.0081c3a9.js)中的同一字段通过普通 input 事件更新关键词，通过 Enter 提交；输入还会调用 `api-c.liepin.com/api/com.liepin.searchfront4c.pc-search-suggest-list` 的 GET。该脚本 3,285,408 字节、SHA256 `865b29d63791601dbfd17e6f5186bf235d20a1fc7326e8b36007b42ec5aa9f75`，本次只做静态阅读。建议请求的许可来自官方源码，尚没有把真实输入时的网络行为写成已观察通过。

- 只对适配器生成的默认关键词地址采用表单路径。包含其他筛选的显式入口保留原条件和原导航检查，不静默删筛选。
- 在原页面、无挑战、唯一可见且可操作的字段上点击、填词，再提交一次。Enter 使用原生 Input 事件，并检查焦点与命中位置；失败不会重复提交。
- 填写和提交前检查取消、页面归属、地址及访问规则。提交保留页额度，立即废弃上一代业务响应。配额拒绝或提交前取消仍保留此前结果。
- 原生列表必须使用与当前地址、关键词、筛选和页码对应的搜索响应。缺少响应时不读旧 DOM 推荐；明确空结果仍需有效的对应响应。
- 实际文档地址由浏览器主 frame 导航记录。仅受控无参数搜索文档在同页更新搜索地址时，读取已取得的页面按原文档检查；真实带参数文档 GET 仍按原 robots 拒绝。
- 正常入口 GET 的 502/503/504 可按已有两次上限、发布方等待和共享额度退避；映射只限默认关键词入口。表单 POST、认证、重定向和其他文档不因此获得自动重放。
- 显式登录只打开正常入口供原账号表单使用，不先要求搜索框可点击或提交关键词。登录后明确继续时用同一会话搜索；从无参数登录入口自动回到原查询仍须单独验证。

精确增加搜索建议 GET 及其 GET 预检；不采用建议内容替换用户关键词，也不把建议作为岗位列表。地区组件依赖与其独立 robots 检查见[地区目录](LIEPIN_REGION_DEPENDENCY.md)。未知接口、POST、错误 Origin 和未审核请求头仍拒绝。

## 验证与剩余问题

单测覆盖一次输入、页面变化、取消、配额、重复字段、当前响应缺失、原生错误保留，以及入口读取的重试映射。人工 HTTPS 场景用真实浏览器经过地区 GET、输入建议 GET、可见输入、Enter、history 更新、搜索 POST、完整 JD 和原报告，另验证实际带参数文档仍被拒绝。成绩必须来自当前提交；本机 Windows 第一次运行被原临时证书信任守卫停止，0 请求、0 场景完成，原结果保留。不会伪造 CI 环境或删除守卫，完整场景在真实 CI 执行。

真实表单提交的全部参数仍待核对。官方搜索 bootstrap 显示日期字段重命名、薪资拆分和查询跟踪字段更新；当前请求配对仍按严格规则工作，可能因此拒绝正常表单请求。这里没有把字段删掉或预先认定成功，下一次已具资格的实站观察应保留第一错误、阶段和脱敏字段对应信息。实际账号登录、会话保存/重启、真实完整 JD→原报告、新控制器在便携 exe 内的执行也仍需各自证据。
