# 按任务选择操作入口

新手先读[从零启动](FIRST_RUN.md)。本文描述当前待审候选，已合并 main 与候选范围见[交付清单](DELIVERY_STATUS.md)，不能仅凭 0.2.0 版本号判断能力。

## 先取得公开职位正文

在首页主动选择“进入猎聘架构师公开分类采集”或“进入猎聘算法工程师公开分类采集”，核对用途、访问依据及每批1～5项后确认。程序从固定主列表取得完整正文并生成本批报告；本批结束后可预览并分别确认下一批或平台下一页。无需搜索 Key 或浏览器账号，也不使用自定义关键词、地区条件。详细范围见[公开分类](LIEPIN_PUBLIC_CATEGORY.md)；这条已有实际数据的路径不替代正常搜索/登录验收，不是失败后的自动回退。

## 找岗位，不整理链接

在 `/guided` 选择平台、岗位关键词、1页/5条数量上限与实际使用范围，点击“打开搜索并读取岗位”。浏览器需要登录时在平台原生页面由你正常登录，然后点击“读取当前列表”或“登录后重新搜索”。勾选卡片，点击“采集所选并生成报告”。观察到的职位URL、最终详情地址和下载文件都由程序整理。

完整操作和错误对照在[按按钮采集指南](GUIDED_COLLECTION.md)。猎聘任务可在本机明确授权单次密码表单，不保存密码；人工验证仍在采集浏览器完成。可另行选择登录后自动接续、本次会话复用或本机 Cookie 保存。它们只通过受控验证，真实账号仍未验通；当前猎聘关键词入口会转空白，BOSS/51job浏览器路径也未认证。未识别、登录、DNS和页面结构错误分别处理，不能用增加预算代替排查。

## 已有URL、Search API或授权数据源

`/advanced` 保留原有的URL / Brave Search / 约定JSON数据源路线，精确字段与留空项见[逐格填写案例](COLLECTION_FORM_CASES.md)。不要在这条旧URL路线期待使用新向导里的浏览器Cookie，它仍是原有受控HTTP获取。

已有更复杂的授权JSON接入、游标、预算、终态恢复需求时，查看[原高级HTTP路线详细手册](LEGACY_HTTP_WORKFLOWS.md)。旧手册中的“页面step驱动”和“不支持浏览器登录”只描述原HTTP路线，不描述新增向导。

## 本人的证据与描述

基础页和向导生成的报告均可在高级页的“选择真实输入报告”中选择。点击“加载原文要求”，查看完整JD、引用和复核状态；需要调整标签时填写复核人、决定和理由。

上传本人附件（或填写外部证据引用），填写姓名、项目、负责范围和实际运行阶段。添加指标时必须有当前值、样本量、观察窗口与比较口径；基线为空时不能声称已经实现同比提升。

在要求列表里勾选本人证据实际支持的条目，点击“保存个人证据”，再点击“生成个人报告”。无证据保存草稿；人工确认不是第三方认证，文件哈希不是经历真实性证明。详细规则见[证据契约](EVIDENCE_CONTRACT.md)和[历史报告保护](REVIEW_GUARDRAILS.md)。

复核按来源报告隔离；同一要求在不同报告中的决定不会相互覆盖。下载证据ZIP时，每个来源报告分别保留对应candidate/reviews与附件；原有高级手册仍详细描述这些不变的导出契约。

## 暂停、关闭与升级

浏览器向导和高级页的公开分类均由后端推进当前已确认批次，关网页不停止；应用须保持运行，暂停/停止控制任务，退出后须明确继续。其他高级 HTTP 路线仍由网页驱动后续步骤。[固定公开目录计划](PUBLIC_DAILY_SCHEDULE.md)可选每24小时运行，[Windows便携包登录启动](WINDOWS_LOGIN_STARTUP.md)另行确认；两者不自动登录三站、不安排分类定时抓取，也不代表无人登录全天服务。

浏览器默认退出不保存 Cookie；明确选择[本机保留](SAVED_SESSION_D04.md)后可在下次任务尝试恢复，仍须核实会话有效。停止浏览器保留已存快照，“清除此平台保存的会话并关闭采集浏览器”才撤销保存。工作区同时保存任务、配额、职位和报告；更新前停止服务并备份完整目录，回退按[兼容说明](WORKSPACE_COMPATIBILITY.md)处理，不删除原数据或配额。
