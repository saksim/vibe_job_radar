# 分类页网络失败后的同页重试

Refs #184 / #166 / #170。

如果公开分类页因网络请求未完成而停止，且尚未取得名单或正文，可在结果中选择“预览失败分类页的同页重试（不联网）”。页面会列出原地址、页号、最多正文数和此次重试次数。确认后只保存暂停任务，网络恢复后点击继续；不会自动重试或重新访问前页。

每份失败任务只有一个确定的重试子任务，重复确认、刷新和重启均打开同一个子任务。每页最多三次显式网络重试；失败记录、已有前页报告、原角色、许可和预算保持，原共享账本继续计量每次尝试。成功后可继续本页名单或平台已提供的相邻页。

此入口仅接纳分类页的 `network_error`，且原分类读取尝试恰为一次、没有候选或正文。拒绝、登录验证、robots不明确、证书异常、未知中断和已经获得部分结果的任务不能由此继续。相邻页仍依赖原已验证的分页关系，执行前重核来源；不接受调用方提供新URL，不更换网络、身份或权限。
