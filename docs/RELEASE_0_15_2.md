# 0.15.2：搜索卡片与可见页面保持一致

## 解决了什么

- #440：搜索卡片现在使用浏览器同一次观察的计算样式副本。隐藏模板、隐藏重复卡片不再抢占去重结果或 300 条结果上限，标题不再混入隐藏后代文字；离线 HTML 使用同一可见性规则。
- #441：单个畸形 href 不再中断整页提取；直接传入畸形 URL 时返回既有 invalid_url 错误。其余有效候选继续保留。

## 提高了什么

现有 BOSS、51job DOM 路径及猎聘旧 DOM 回退更准确、稳定。保留原 title 属性、选择器、身份参数、URL 校验、可见后代、原始 HTML 和 300 条上限；猎聘结构化业务响应仍优先，缺失必要业务响应不会降级为伪成功。原采集、完整 JD、报告、网络、团队服务、升级与备份功能保持。

基线为已正式发布的 0.15.1/main `0f0310118b431bee3610515743caa0096e3959b1`。开发前 dev、release 均已 rebase main，无分叉。
