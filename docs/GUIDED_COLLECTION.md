# 不整理链接的采集向导：按按钮操作

本文描述当前待审候选。相同的 0.2.0 版本号不代表 main 已包含全部功能，源码范围以[交付清单](DELIVERY_STATUS.md)和所选 PR 提交为准。先区分两个窗口：**工作台**负责点按钮、看进度；**采集浏览器**负责打开招聘网站、登录、搜索。日常 Edge/Chrome 登录不会让程序的独立采集浏览器自动登录。

## 先取得数据：可主动选择猎聘公开分类

当前已有实站正文和原报告证据的是[猎聘公开分类](LIEPIN_PUBLIC_CATEGORY.md)，可从首页选择“进入猎聘架构师公开分类采集”或“进入猎聘算法工程师公开分类采集”。这是无需账号、浏览器组件或搜索 Key 的 HTTP 路线；打开入口只填写预设，确认前不请求网站。

1. 核对类别、每批 1～5 项的范围和实际用途，填写适用的访问依据并确认执行。
2. 程序从发布方主列表选取职位，核对身份与完整正文，入库并生成本批报告。查看每条成功/失败，列表链接数不等于完整正文数。
3. 本批结束后，可分别预览“这份名单的下一批”或“平台下一页”；预览不联网，确认后才开始新的小批。原成功、失败和报告保留。

固定分类不使用自定义关键词或地区条件。算法工程师是宽分类，报告会单列未匹配原目标岗位规则的正文。分类取数不证明正常登录或关键词搜索已经验通，也不会在浏览器失败后自动替换路线。

## 需要关键词搜索或验证登录时

下面是 `/guided` 浏览器向导的按钮流程。猎聘原生实验模式已在本机 Edge 取得一页42张关键词搜索卡；正常登录、所选完整JD及原报告仍待实测，默认浏览器桥不能继承这次原生观察。BOSS 所测详情要求登录/验证，51job 访问契约仍不可用。遇到错误应保留原因，不反复点开始，也不能把提供密码当作修复页面错误的方法。范围见[当前取数证据](CURRENT_ACQUISITION_EVIDENCE.md)和[采集能力](ACQUISITION_CAPABILITIES.md)。

## 已经能打开工作台，就从这里开始

不必更换你的 Python 或 Anaconda。完整取得所选候选或 main 对应的源码，停止旧终端并备份工作区，用原来成功的解释器在新源码目录运行。Git Bash 示例：

```bash
/d/code_environment/anaconda_all_css/py312/python.exe scripts/start_workbench.py
```

打开这次终端给出的完整地址，再点击首页的“新手推荐：选平台 → 找岗位 → 勾选采集”。地址会进入 `/guided`。端口每次可能变化。Python 没升级源码不会自动更新；只刷新旧网页不够。

## 第一步：准备浏览器，只做一次

先点“检查浏览器（不采集）”，按需安装。第1步的“安装 / 修复采集浏览器”在确认后使用启动工作台的**同一 Python**安装 Playwright 和 Chromium，不要求更换虚拟环境。只有实际空白页启动检查通过才算就绪；命令成功但启动失败显示 installed_not_ready。也可明确选择本机已安装的 Edge 稳定通道并点击“检查并使用所选浏览器”，不会读取日常浏览器资料。公开分类和基础页粘贴分析不依赖此安装。

此按钮不会读取你日常浏览器的 Cookie。

先点“检查浏览器（不采集）”可验证已有环境，展开“浏览器诊断、修复命令与安装日志”查看解释器和预期文件。误装 `Chromium-0.0.0` 的解决方法见[浏览器安装与启动修复](BROWSER_SETUP.md)。

## 第二步：告诉程序要找什么

以研究时间序列岗位为例：

| 字段 | 第一次怎么填 |
|---|---|
| 招聘平台 | 选择本次要验证的平台；三站浏览器路径仍未实站认证 |
| 分析岗位类别 | 时间序列算法工程师 |
| 搜索关键词 | 时间序列算法工程师；城市筛选可在采集浏览器里手动调整 |
| 最多读取列表页数 | 1 页 |
| 最多采集岗位数量 | 5 个；排障时改1个 |
| 允许使用的依据与用途 | 填实际适用的访问说明/提供方许可和用途；不是另一把 API Key |
| 执行确认 | 核对访问条件后本人勾选 |
| 可选“搜索结果列表地址” | 没有就留空；程序自己构造站内搜索地址 |

点击“打开搜索并读取岗位”。本向导不要求职位 URL 清单、搜索 API Key、数据源地址、分页游标或 CSS 选择器。可选“搜索成功后，按本次查询的返回顺序自动采集前 N 个岗位并生成报告”，默认关闭；开启后仍按本批上限执行，遇到登录/验证时暂停，不自动提交密码。

若你本来已经有一个搜索结果页面，可展开可选项，把**包含多个职位的列表页**地址粘进去。程序将识别其中真实存在的详情链接，不是让你逐个复制。

只找到0条、看到登录提示或遇到网站改版，不表示一定是填错关键词。继续按下面的提示处理；没有找到的链接不会被编造出来。

## 第三步：要登录，就在采集浏览器里完成

点“打开登录浏览器 / 人工接管”。在弹出的采集浏览器正常完成扫码、短信验证码或登录。网站只提供短信/扫码时，不存在可以靠填密码解决的通用登录方式。

猎聘任务另有“猎聘：自动填写密码并提交一次”：在本机表单输入并明确授权后，只填入网站当前可见表单并提交一次，不保存密码、不自动重试。该功能已通过受控验证，**真实账号登录仍未验通**。协议、短信码、扫码和验证码由你在采集浏览器中处理。不要把账号密码、Cookie 或验证码发到聊天或 Issue。详见[密码登录范围](LIEPIN_PASSWORD_LOGIN.md)。

默认不保存登录 Cookie。需要尝试重启复用时，在第2步明确勾选“在此工作区本机保留该平台 Cookie 会话”；只保存程序专用浏览器的本站 Cookie，不保存密码，恢复后仍由正常页面判断有效性。停止浏览器保留已保存快照，主动撤销时使用“清除此平台保存的会话并关闭采集浏览器”；岗位、报告和配额保持。快照超过7天不再复用，依赖 localStorage/IndexedDB 的登录尚不支持。保存位置、Windows 加密与其他系统权限说明见[本机会话恢复](SAVED_SESSION_D04.md)。

勾选“本次登录返回原列表或所选岗位详情后自动继续”后，正常返回可读页面会接回原任务。需要在同一次运行中更换查询时，第2步另有“复用当前空闲采集浏览器的同平台会话”；它不自动启用持久保存。未启用自动接续时使用下面的原按钮。

完成后有两种简单操作：

- 已在采集浏览器打开需要的结果列表：回工作台点“我已打开结果列表：读取当前列表”。
- 只完成登录、还没有搜索：点“登录后重新搜索”。

请勿在采集浏览器里投递简历、发消息、修改个人资料。本工具的自动动作只针对正常登录及只读采集。

## 第四步：勾选岗位，URL 由程序输出

下方显示岗位卡片、列表观察到的真实详情链接和每条状态。勾选需要研究的岗位，或者点“选择本页岗位（不超过上限）”，再点“采集所选并生成报告”。

程序按顺序打开详情、处理允许范围内的导航、保存最终详情地址、提取独立正文、去重入库，调用原分析引擎生成报告。最终跳转地址显示在卡片上；“下载已发现的职位链接”可导出整份观察链接清单。未打开的卡片只有列表观察地址，不能冒充已经验证的最终跳转地址。

本批报告只使用**这次勾选且成功入库的记录**。有报告不代表每个岗位都成功；请看每条卡片的结果。下载“岗位要求 CSV”核对原文，再下载描述模板；本人项目、附件和量化指标仍在高级证据中心编辑。

## 等待时可否关网页？

不要按刷新次数判断是否卡住。默认强制频次（同一工作区、同一平台跨任务/进程共享）：

| 动作 | 硬限制 |
|---|---|
| 页面导航/翻页 | 至少15秒间隔，最多60次/小时、200次/滚动24小时 |
| 经采集后端桥接的 HTTP 请求 | 至少0.5秒间隔，最多600次/小时、3000次/滚动24小时 |
| 打开登录窗口 | 至少5分钟间隔，最多3次/滚动24小时；请复用已打开的登录窗口 |
| 一批列表/详情 | 最多5页列表、20个选中岗位，默认1页/5个 |

页面的脚本、样式、robots 和登录请求也进入 HTTP 台账；一个页面通常不止一个请求，重定向可能消耗额外导航配额。限频中的“等候”不是挂住；界面不能将速度调高。站点的更严限制优先；严格延迟策略暂不兼容时会停止，不默默忽略。

主文档/必要API返回401/403或任何资源返回429时停止，并记录至少5分钟的持久化冷却；429的更长 Retry-After 会保留。可选资源401/403只中断对应请求，不误触发整站冷却。没有自动账号池、代理池或验证码破解。错误后由用户确认是否继续，不无限重试。

浏览器向导和公开分类的已确认批次均在本机后台执行，**关工作台网页不会停止当前批次**，应用须保持运行。暂停等待当前网络调用结束后停止后续动作；停止浏览器任务会关闭采集浏览器。退出应用保留检查点，重启后须明确继续；未选择保存或会话失效时需要正常重新登录。其他高级 HTTP 路线仍由网页驱动后续步骤，不能套用分类后台规则。

固定公开目录另有默认关闭的[每24小时查询计划](PUBLIC_DAILY_SCHEDULE.md)和[独立执行进程](PUBLIC_WORKER.md)。Windows 便携候选可明确启用[登录 Windows 后启动](WINDOWS_LOGIN_STARTUP.md)，源码版仍手动启动。这些功能不自动登录招聘平台，不安排猎聘分类定时抓取，也不保证无人登录全天服务。不要同时从两份工作台操作同一任务。

## 看到错误时按这里处理

| 提示 | 含义和下一步 |
|---|---|
| 浏览器组件未就绪 | 点第1步安装/修复；不要更换已经能启动的Python |
| non_public_address / 198.18.* | 点“网络检查”看解析地址。这可能是代理 Fake-IP；先修正DNS/TUN配置。不是缺少登录，不能关闭安全检查来解决 |
| 需要人工操作 | 在程序弹出的浏览器正常登录/验证/搜索，然后读取当前列表 |
| native_page_cleared / 搜索页转空白 | 主页面已被清空；保留原因并停止本次尝试，不把它当作零岗位或密码错误，不反复提交 |
| 0个岗位链接 | 页面可能未加载、需要登录或列表结构不兼容。手动打开正确列表后读取；仍为空说明适配需要修正，不编造URL |
| robots_denied / robots_unavailable | 当前路径不满足自动访问条件；转获准接口或基础页的有权处理文本 |
| http_403 / http_429 / cooldown | 停止请求；核对权限/限流，不靠新建任务重置配额 |
| structure_changed | 无法确认独立完整JD，未把整页推荐内容当作正文；可在基础页粘贴完整文本 |
| resource_domain_blocked | 页面资源不在适配器允许域名中，需维护人员审核添加；不要全域名放开 |
| 停止后再继续 | 当前浏览器已关闭；已明确保存的 Cookie 可在绑定条件匹配时尝试恢复，失效则正常登录。已成功岗位保留 |
| 安装失败 | 检查下载网络、磁盘权限；固定安装不会自动绕过企业网络限制 |

## 当前诚实的能力边界

公开分类和单条公开详情已有实际取数、完整正文和报告证据；三家招聘平台的正常浏览器搜索、真实账号登录和会话恢复仍标记未实站认证。受控浏览器/程序测试不替代现场验收，跨日期与用户全文复核继续按[交付清单](DELIVERY_STATUS.md)记录。

也不是“全市场职位穷尽”：卡片来自本次观察到的列表，未知总量时不能算全市场覆盖率。单纯登录不能解决DNS、robots拒绝或页面结构不兼容。

## 合并前回归修复

列表显示后，采集浏览器的后台轮询会冻结，避免你只是在勾选岗位也不断消耗请求；下一次明确操作才恢复。打开登录窗口至少间隔5分钟、滚动24小时最多3次；请复用已打开的原生登录窗口。

正常跳转翻页与不跳转的动态翻页都只扣一次页面动作额度。可选图片/字体/脚本的401/403不会将整个任务误判为登录失败；主文档、必要接口拒绝和任何429仍停下，网络安全检查不放宽。

后面的岗位被阻挡时，前面已经成功的岗位也会生成可下载报告；任务继续显示真正的阻挡原因，不伪装全部完成。自定义站点会将平台配置保存在本批报告里；报告和CLI的版本统一来自同一版本定义。
