# 猎聘架构师公开分类

在原自动采集工作台点击“自动读取猎聘架构师公开分类”，核对本次用途、分类页和正文的访问许可后执行。不需要搜索 API Key 或逐个复制职位链接。

程序读取发布方首页提供的 `https://www.liepin.com/career/360321/`，只识别主职位列表，按页面顺序选取前 1～5 个不同职位，经过完整正文和职位身份检查后入库，生成仅包含本批成功记录的原报告。默认选择 5 项；少于预算时按实际数量显示，失败项不以后续岗位补齐。任务保存分类结果、顺序、全部已选结果、请求诊断和解析版本，支持暂停与重启。中断时未知的请求不会自动重放。

本批结束后，点击“预览这份名单的下一批（不联网）”查看下一组具体职位，核对后点击“确认采集这批职位”。程序使用同一页保存的名单，每批继续原先的1～5项预算，不重新读取分类页，不跳回已选失败项，也不修改旧任务和报告。重复确认只返回同一个已保存任务；从该任务的结果继续可逐批读取后面的名单。末批不足预算时如实显示，名单耗尽只说明这个快照已选完。

预览保留名单的原读取时间。旧版本没有准确读取时刻时，明确显示“旧名单未记录准确读取时刻”及来源任务建立时间，不能把继续执行日期称为名单更新日期。每批正文与报告仍记录自己的实际采集时间。访问拒绝、登录验证、TLS异常或未知中断会阻止下一批，需先处理原因；不会用新批次绕过它们。每次确认授权本批预算，旧批次的尝试不退款。

这是固定职业分类，不包含自定义关键词、地区筛选或翻页，也不验证账号登录与浏览器会话。保留正常 HTTPS、robots、网络设置、节奏和拒绝处理；不会在其他路线失败后自动切换到本路线。分类读取次数和正文尝试次数均不等于全部 HTTP 请求数，访问可能包含 robots 或受限跳转。

目前严格正文路径覆盖无参数的 `/job/<数字>.shtml` 和 `/a/<数字>.shtml`。无法识别的卡片仍计入已选结果并显示失败，不发该条正文请求。结构变化或没有可确认卡片会报告待核验，不能解释为市场上没有岗位。列表数量不是完整 JD 数量。

`/a/` 类型来自该主列表的实际链接，已单独取得一份身份一致的575字正文。它也必须通过严格身份和完整性检查，旧通用缓存不能跳过新检查。该类型没有沿用 `/job/` 分享参数移除规则：带未知参数时保留原路径和参数，继续服从robots。实测和剩余验收记录在 Issue #148。

2026-09-24 已确认该官方分类入口正常 HTTP 200，原始主列表有 34 个不同详情链接；这是列表观察，完整 JD 与现场验收另见 Issue #146。原始 HTML、JD 与报告留在本机，不提交到仓库。人工回归和 CI 不使用真实招聘内容、不认证三站或30岗/3日期目标。
