# 猎聘正常密码登录与取数阻塞（2026-09-23）

本轮接续 PR #62，关联 #49（首条真实 JD）和 #50（正常登录/会话复用）。
新增的是可测试的一次正常表单提交能力；没有真实账号登录成功证据，不能据此关闭 G1 或 D04。

## 可用行为

向导第 3 步增加“猎聘：自动填写密码并提交一次”。用户在本机输入自己的账号密码并授权本次提交后：

1. 保留原查询或下一条未完成的所选岗位，在程序拥有的猎聘页面打开登录。
2. 点击页面的“密码登录”，填写当前可见表单并点击一次登录。使用网站自身 JavaScript，不构造或重放密码 API 请求。
3. 密码仅通过受本机令牌和 Origin 校验保护的现有工作台 API 进入工作线程；不写任务、报告、诊断或 Cookie 快照。界面立即清空，线程结束和浏览器填表结束均释放引用；Python 字符串不能保证内存擦除。
4. 正常返回本任务可读列表/完整所选详情后，沿用既有两次稳定观察与采集接续。启用“搜索后自动采集前 N 个”可继续已有选岗、入库和报告流程。
5. 平台协议、验证码、短信验证、密码错误由平台页面提示处理。程序不勾选协议、不处理验证码、不重试密码。已恢复的 Cookie 会话仍由正常页面实际结果判断可用性。

手动登录勾选自动接续时保留原查询意图。原生模式的无关键词入口在账号区域与搜索框连续可见、登录/验证控件消失后，重新核对原任务并提交原关键词一次；带显式筛选、已有结果或所选详情不改作新搜索。具体条件见[登录入口接续](LOGIN_SEARCH_ENTRY.md)。这仍需本人账号与实站验收。
旧手动登录 API 继续拒绝密码，单独的 `login_password` 动作只支持猎聘，并要求一次授权。

## 页面依据与请求范围

2026-09-23 读取了 [猎聘公开首页](https://www.liepin.com/) 当时引用的
[官方 common.0081c3a9.js](https://concat.lietou-static.com/fe-www-pc/v6/js/common.0081c3a9.js)。
对应表单提供 `data-nick="login-user"`、`data-nick="login-pwd"`、`button.login-submit-btn`；
入口为 `#header-quick-menu-login`，切换文字为“密码登录”。

该脚本列出了 `https://api-passport.liepin.com` 下的账户操作。
本轮仅在明确的认证模式开放精确的 `account-pwd-login`、`check-login`、`v2.check-login`、`get-category` POST 与受限同源预检。
角色标为 login，其响应不进入岗位业务观察队列。桥接模式复用精确操作匹配，并补足页面实际引用的两个静态资源域。
不开放注册、改密、投递、消息、任意 API、二维码或跨站 SSO；未适配请求仍会停止。
正常页面初始化另读取一个精确的[登录界面配置](LIEPIN_LOGIN_UI_CONFIG.md)，不生成/轮询二维码或提交账号，响应不进入岗位队列；密码提交仍要求原认证模式和本次授权。
公开脚本只能证明接口/表单存在，不能证明完整实站依赖链已经运行成功。

## 本次实站读取的结果

- [www.liepin.com/robots.txt](https://www.liepin.com/robots.txt) 返回 200 text/plain，包含 `Disallow: /*?*`；本项目现有采集规则会阻止带关键词查询参数的搜索 URL。
- `api-c.liepin.com/robots.txt` 与 `api-passport.liepin.com/robots.txt` 返回 404。后续迭代已将此情况与访问拒绝区分，继续已有请求契约内的访问，见 [robots 状态处理](ROBOTS_STATUS_HANDLING.md)；不代表完整登录链路已实站通过。
- 不带查询参数的 `/zhaopin/` 可读取，但本次 HTML 没有提供可确认的职位卡片，不计作搜索成功。
- 首页实际给出的 `/job/1918256957.shtml` 返回“该职位已暂停招聘”，没有该岗位完整正文。新增 job_unavailable 结果，避免把过期职位误报为解析故障或登录失败；也不采用推荐岗位冒充。

所以：本次没有取得新的完整真实 JD，没有真实账号认证证据。后续必须解决/确认实际可用的搜索访问入口及完整站点依赖，并进行用户本机账号验收，不能靠人工测试宣称全自动采集完成。

## 验证方法

- `python -m unittest discover -s tests`：包含隐藏模板与可见验证页、已下线职位、密码单次授权/字段校验、任务与状态不含密码、异常清理、原查询接续和精确请求规则。
- `python scripts/verify_password_form.py --channel msedge`：真正启动隔离 Edge，对全部 URL 返回本地人工 HTML，验证一次提交、验证码暂停、外部表单拒绝、取消、表单变化。外部请求为零，不使用真实账号。
- 所有新登录验证均是受控验证；实站读取的原始 HTML 与临时公开脚本留在忽略目录 `.verify`，不提交原始页面、账号或第三方脚本。
