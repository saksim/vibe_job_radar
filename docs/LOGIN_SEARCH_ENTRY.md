# 从登录入口继续原关键词

原生猎聘为显示正常登录控件，会先打开无关键词搜索入口。旧接续器只等待原关键词列表，登录完成仍停在入口时不会继续；新增测试在旧代码上已实际复现两次稳定读取后仍未排入原搜索。

本次自动接续只适用于已明确选择它的原生猎聘任务、查询范围版本1、原关键词地址且尚无卡片、选择或已冻结筛选。带显式筛选的地址、原有结果和所选正文仍沿用各自返回路径，不丢弃条件改作新查询。

页面依据是2026-09-25已保存的官网公共脚本（SHA256 `865b29d63791601dbfd17e6f5186bf235d20a1fc7326e8b36007b42ec5aa9f75`）。其登录态页头与未登录入口分支不同，账号区域标记为`header-quick-menu-user-info`。这里只观察结构是否可见，不读取账户名称、图片、Cookie或登录响应。这段静态代码不是实际账号认证证据。

接续须同时满足：当前是原无关键词入口文档；账号区域与搜索输入框各有一个可见元素；登录入口和密码框不可见；无验证/拒绝，原浏览器及网络检查通过。连续两次观察的文档导航代次必须相同，原十分钟截止时间不延长。输入前原工作线程再读取第三次，核对同一浏览器、原查询、授权和页面签名；变化、取消或停止均不输入，不新建替代浏览器。

通过后使用既有正常表单路径填原关键词并按一次Enter，网站脚本生成请求；随后走原列表、已授权的前N条选择、完整JD入库与原报告流程。不重导航入口，不构造API，不重新提交密码。搜索失败、配额不足或被拒绝时保留实际结果，不由这个接续动作再次搜索。

旧普通DOM、其他平台、人工默认未勾选接续的行为保持。内部接续动作不对HTTP操作API开放；队列只携带原查询与摘要，不携带HTML、账号值或密码。可读列表、可用账号控件及任务继续均不等于真实账号认证验收。

测试覆盖正向两次观察/第三次重验、缺失或重复控件、验证/原生拒绝、取消、原截止时间、导航/浏览器/关键词/授权/筛选变化、空交接签名、一次输入后走原收集且失败不重试。人工HTTPS场景使用合成账号区域与已存在的人工登录Cookie，在真实浏览器验证正常表单一次提交；实际招聘站、本人账号和长期会话仍另行验收。
