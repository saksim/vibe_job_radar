## 本轮独立代码修订，尚待正式交付

- #479 HTTP CONNECT总预算：原固定单次接收超时允许缓慢分片头部反复延续等待，且拨号耗时未在CONNECT发送前扣除。修订使用原绝对截止期约束发送和底层读取，成功后交回原socket；没有改协议选择、认证、TLS或期限。
- #480 原生管道构造：读线程已启动而写线程启动失败时遗留自有stdin/线程。修订释放自有控制输入并有限等待已启动线程，保留原始启动异常。
- #481 原生隧道关闭：某阶段异常会跳过其余清理。修订分别尽力释放自有资源并保留首个异常，既有等待上限和PID/profile保护保持。
- #482 计划恢复：恢复同实例活任务时丢失任务身份，导致计划停止无法再关联该任务；恢复时完成记录又会覆盖时钟回拨事实。修订保留匹配的活任务及原停止权限，回拨时沿用既有暂停规则并保留完成报告。

这些是人工本机夹具确定性复现后的产品代码修订，不是仅整理文档或增加观察器；已有定向负/正对照与必要相关检查。配对Issue为#479–#482；PR、候选和main CI及Tag以实际交付记录为准，不提前宣称发布。四项历史根因仍各自未证实，不能全部归为“用户没提供材料”。
