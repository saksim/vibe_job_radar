# 继续因等待未完成的公开分类正文

适用于已经读取猎聘架构师或算法工程师分类名单、正文阶段因共享访问间隔、发布方等待、小时/日限额或已有冷却而停止的任务。

在原任务结果里点击“预览因等待未完成的正文（不联网）”。核对具体岗位、继承的成功数量、用途与本次最多5条正文尝试，再点击“确认保存恢复任务（暂不联网）”。新任务保持暂停。等待原因解除后，点击“继续所选任务”；原工作区账本仍会检查额度、冷却和发布方规则，不能因为已创建恢复任务就提前访问。

新任务只重选本批因等待未完成的条目，不刷新分类名单、不选择其他岗位、不重取已有成功。报告包括原批已有正文和本次成功；继承数量明确标注，保留实际采集日期。其他失败仍显示，旧任务、原报告和预算保持不变，不退款。页面刷新或进程重启后，从历史任务打开恢复任务即可；重复确认返回同一个任务和报告，不能重放已完成的访问。同一原批次最多3次显式恢复。

每步校验原任务指纹、分类/分页祖先、许可、解析版本、岗位身份和本次预算。继承的原正文通过只读数据库验证；缺失或内容变化时停止，不静默生成少掉旧结果的报告。恢复完成后仍可按原条件继续本页下一批或平台相邻页。

401/403/429、登录或验证、robots拒绝、证书、时钟回退、坏账本以及结果未知的中断不属于这个恢复入口；尚未读到名单也不能恢复正文。需要先核对具体原因。此功能不是定时自动重试，不认证真实账号登录、会话过期恢复或所有崩溃情形；#52的完整目标继续独立验收。

验收使用默认Collector/SiteFetcher、临时持久账本及人工上游响应。原Edge流程验证等待后只取剩余正文、报告与重复打开；Windows便携验收验证实际程序的只读预览、暂停保存和新进程重启，不从人工检查点发送招聘请求。受控验证不是刻意触发真实网站限流，也不替代实站认证。
