# 跨平台域名 PAC

0.9.0 增加显式的“跨平台域名”和“跨平台域名 + DNS助手”。Windows、Linux、macOS 的 Python 安装使用已有 `pac` 可选组件；Windows 便携包内置该组件。原 Windows WinHTTP 域名 PAC、系统 PAC、WPAD、完整网址 PAC 和固定代理继续保留。

三个工作台的“网络偏好”中选择执行范围，导入可信 UTF-8 PAC 文件并勾选说明。文件最多 64KiB。选择、导入、保存和读取状态不会执行脚本或查询 DNS。点击“检查脚本”才执行固定人工域名；检查不会连接脚本返回的代理或目标。

## 传入内容与路线

`FindProxyForURL(url, host)` 只收到规范的 HTTPS 根地址和小写域名，例如 `https://example.com/` 和 `example.com`。职位路径、查询参数、Cookie、请求头和正文不会传入脚本。HTTP、浏览器请求桥和原生浏览器的 CONNECT 共用此域名选择。

每个会话对同一域名只采用首次结果，含错误；最多 128 个不同域名。不同路径或时间变化不会重新执行或换路线。需要重新求值时，停止并新开会话。

支持 DIRECT、匿名本机 HTTP PROXY 和明确的匿名本机 SOCKS5。沿用原返回值校验，只用第一项；拒绝、超时或未知指令都停止，不继续下一项。实际请求保留公网 IP 校验、原站 SNI/TLS、来源许可和访问频次。公共加密解析沿原目标域名的路线，不因解析商域名重新选路。

## 可选 DNS 助手

普通“跨平台域名”提供五个字符串和三个日期时间助手，与[完整网址 PAC](FULL_URL_PAC.md)使用同一明确语义；不提供网络、文件、DNS 或本机地址接口。

“跨平台域名 + DNS助手”需另行选择并同意，才提供 `dnsResolve`、`isResolvable`、IPv4 `isInNet` 和 `myIpAddress`。可信脚本可向系统解析器提交自选名称；DNS 服务可能看到名称，脚本可以读取系统主机名解析得到的首个 IPv4。它不是代理端 DNS，也不保证多网卡出口判断。每次求值最多 16 个不同名称，实际目标仍必须通过公网和 TLS 校验。

固定 QuickJS-NG 引擎运行在应用自有短命进程中，复用原来的 16MiB 堆、512KiB 栈、8 秒共同期限和最多两个并发进程。普通模式还有 4 秒引擎 CPU 限制；DNS 模式使用宿主回调，由父进程共同期限结束阻塞操作。进程调度与回收可能延迟返回。这是可信脚本功能，不承诺隔离恶意原生引擎漏洞。

## 保存、撤销与回退

普通范围使用 schema 9、`pac_domain`、`workspace-trusted-portable-domain-pac-v1`；DNS 范围使用 schema 10、`pac_domain_dns`、`workspace-trusted-portable-domain-pac-dns-v1`。旧模式许可不会扩大。两者共享现有工作区内容摘要副本保存，不改系统代理或自动发现 PAC。

修改 DNS 偏好保留当前脚本许可；重导入、更换代理、文件变化或丢失、取消和工作区关闭会撤销旧会话建立新连接的能力。已经发出的请求或既有连接不能撤回。缺少可选组件时明确停止，并保留在工作台切回自动模式的入口。

0.8.0 及更早程序不认识 schema 9/10，会拒绝读取，不能静默改为直连。降级前先在新版将代理改回“自动发现”或旧版支持的其他模式；保留个人材料和报告。

## 验证范围

本机 52 项定向检查覆盖实际隔离引擎、人工 HTTP/SOCKS5 + TLS、API token/origin、工作区重开与撤销和新旧发行门禁。实际 Edge 的三个页面验证独立范围、只传根地址、撤销和 390px 布局，外部请求和页面错误均为零。首次本机缺少可选组件的停止记录保留，复用已有固定版本运行库后通过。

CI 在原有 Linux Chromium、Windows Edge/Chrome 的有头/无头作业内追加人工列表、完整详情和代理拒绝验证；Windows 冻结程序增加实际 API 证明，正式发行必须核对该证明。当前提交的实际结果见对应 PR/Release，不提前视为通过。

Mac 原生浏览器、企业实际 PAC/VPN、多网卡、真实来源和账号认证仍需现场环境；本功能不包括跨平台系统 PAC/WPAD 自动发现、远程认证代理、NTLM/Negotiate 或代理端 DNS。
