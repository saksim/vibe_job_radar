# 原生搜索请求与本次结果绑定

关联 #63 / #196 / #57 / #210。当前准备日期：2026-10-03。

猎聘页面按网站自身格式转换发布日期、薪资范围、建议标识和交互字段时，原生采集必须验证URL与请求体的对应关系。初始无关键词页面的推荐数据不能算作用户搜索结果；正在等待本次返回时，也不能用旧DOM中的职位链接代替。

此范围复用原196的精确字段映射和原始回归，并保留当前SDK/Chrome控制方式。只有原生猎聘快照要求自己的查询响应；其他适配器和旧DOM输入仍走原路径。完整匹配的新响应及确认空结果优先于过期DOM；未知字段、重复字段、筛选变化和非标量值继续拒绝。初始化推荐页的 confirmed_empty 返回false，其他错误继续向上传递。

单元原型初次对照23方法24错误；第一次整合138测试3错误（遗漏初始化页谓词与测试import），原日志保留。补齐必要产品谓词和测试import后，186相关搜索/JD回归零失败、错误和跳过；没有降低原断言。当前JD解析除confirmed_empty外保持逐方法AST一致。

新增四个CI人工场景：公开格式完整绑定并落库/原报告、确认空结果、字段不匹配、缺少当前响应。每个场景都保留过期DOM链接，验证其不能冒充本次结果。原生浏览器执行尚待首次CI；本机只做静态检查，不运行证书夹具。人工样本不计作真实搜索、登录或多日期实采成果。

本范围不实现可见搜索输入与登录后同一窗口自动返回。后续必须兼容SDK和直接CDP的页面身份观察，保留现有页面隔离、条款交接与登录配额。
